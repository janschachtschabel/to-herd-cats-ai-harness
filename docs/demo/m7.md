# Demo M7: Automatisierung

Abnahme von Meilenstein 7 (Spezifikation 14): „Ein Zeitplan läuft bei drei
Worker-Replikas genau einmal; eine Agentenkette stoppt bei Tiefe 3.“ Dazu die Demodaten
mit Aufgaben, Heartbeat, Ereignis-Regel und Budgets (Plan M7, Task 10), ein Heartbeat,
der mit `HEARTBEAT_OK` still bleibt, ein Budget, das einen Lauf stoppt, und die tägliche
Prüfung der Seiten mit drei Workern.

## Was die Demodaten dazu anlegen

`backend/scripts/demo_seed.py` ruft mit eingestelltem Modell (dieselben Variablen
`HERD_DEMO_AI_*` wie in [M6](m6.md)) nach den Agenten `backend/scripts/demo_automations.py`
auf, alles über die öffentliche API:

- **Annas Tageszusammenfassung:** Otto, werktags 08:00 (Europe/Berlin), in #team-nord;
  einmal „Jetzt ausführen“, sodass das Protokoll einen Termin und der Kanal dessen Thread
  mit der Antwort hat (im Kanal steht „Aufgabe von Anna Nord gestartet.“, nicht der
  Auftrag);
- **Bens Heartbeat:** Hilda, stündlich Mo–Fr 08–18 Uhr in Bens Direktnachricht mit ihr,
  mit einer Checkliste; einmal ausgeführt, Antwort `HEARTBEAT_OK`: Das Protokoll vermerkt
  es, zugestellt wird nichts;
- **eine Ereignis-Regel** der Verwaltung (Ereignis-Regeln legt nur an, wer den Bereich
  verwaltet): Otto, bei `ticket.created` mit dem Schlagwort „kranich“, in
  #projekt-kranich, Ruhezeit 5 Minuten;
- **Annas Wochenerinnerung** mit Otto in ihrer Direktnachricht, von Hand angehalten;
- **Budgets:** die Organisation (2.000.000 Tokens und 25,00 EUR am Tag) und Otto
  (200.000 Tokens am Tag);
- **Prüffrist** von 90 Tagen für Team Nord.

Eine Seite mit fälliger Prüfung lässt sich über die öffentliche API nicht in Echtzeit
erzeugen: Veröffentlichen gilt als Prüfung, und die kürzeste Frist sind 7 Tage. Das Demo
unten stellt dafür die Uhr seiner Prozesse vor.

## Die Uhr

API und Worker laufen im Demo über `python -m tests.support.e2e_clock` statt
`python -m app.launch`: Dieser Starter aus dem Testbaum addiert auf die Uhr, nach der
geplant wird (`app.core.clock.SYSTEM_CLOCK`: Fälligkeits-Schleife, Ereignis-Regeln,
Verwaltung der Aufgaben, Seitenprüfung), einen Versatz in Sekunden aus einer Datei
(`HERD_E2E_CLOCK_FILE`) und startet dann `app.launch` wie gewohnt. Alles andere (Leases,
Sitzungen, der UTC-Tag der Budgets beim Modellaufruf) bleibt bei der Systemzeit. Der
Versatz ist 0, bis das Skript ihn ändert: für das Ende der Ruhezeiten der Kette (je
61 s) und für die Seitenprüfung (31 Tage). Die Browser-Tests nutzen denselben Starter
(`e2e/global-setup.mjs`, `POST /clock` auf dem Steuerport).

Im Produkt gibt es ihn nicht: Das Image kopiert nur `backend/app` und `backend/alembic`,
nichts unter `app/` kennt den Starter oder die Variable, und er verweigert
`HERD_ENVIRONMENT=production` (`backend/tests/test_e2e_clock.py` prüft alle drei).

## Ablauf

1. `demo_seed` legt die Demodaten von M1 bis M6 und die Aufgaben oben an.
2. `demo-m7.mjs` prüft diesen Stand und dann:
   - **Abnahme 1, drei Worker:** Die Verwaltung legt 50 einmalige Aufgaben an, alle zur
     selben Sekunde fällig (25 s später, echte Zeit, ohne Uhr). Die drei Worker feuern
     sie: genau 50 Termine für 50 Aufgaben, 0 doppelte, genau ein Lauf je Aufgabe, alle
     beendet. Den Anteil jedes Workers zeigt sein Zähler
     `herd_automation_firings_total{outcome="started"}`.
   - **Dasselbe mit einem abgeschossenen Worker:** 50 weitere; sobald Worker 2 einen Termin
     gefeuert hat, wird seine Prozessgruppe mit SIGKILL beendet. Wieder genau 50 Termine,
     0 doppelte, ein Lauf je Aufgabe; danach startet Worker 2 neu.
   - **Heartbeat:** ein Heartbeat in einem neuen Kanal #puls antwortet `HEARTBEAT_OK`:
     Das Protokoll sagt es, der Kanal bleibt leer, kein `message.*`-Ereignis in der
     Outbox, keine neue Aktivität für Anna oder Ben. Mit etwas zu sagen: der Eintrag des
     Termins und die Antwort im Thread.
   - **Abnahme 2, Kette:** Eine Regel auf `ticket.created` in einem eigenen Bereich
     „Kette“; Kai (Stufe 2) legt in jedem Lauf ein Folgeticket an. Nach dem Ticket einer
     Person laufen Tiefe 0, 1, 2, 3; das Ticket des vierten Laufs wird mit
     `skipped_depth` protokolliert, ohne Lauf. Fünf Tickets.
   - **Budget:** Bruno hat ein Tageslimit von 1 Token. Sein Lauf darf den ersten
     Modellaufruf machen und endet vor dem zweiten mit `budget`; der Hinweis am Ort nennt
     das Limit des Agenten; der nächste Termin ist `skipped_budget`.
   - **Seitenprüfung mit drei Workern:** Die Verwaltung kürzt die Frist von Team Nord auf
     30 Tage, die Uhr springt 31 Tage vor. Jede fällige Seite (Handbuch, Urlaub; nicht
     Ottos Gedächtnisseite) bekommt genau ein `page.review_due`, jede moderierende Person
     je Seite genau eine Aktivität; das bleibt so über zwei weitere Runden jedes Workers.
   - Clara (keine KI) bekommt auf `/api/automations` 404.

Die Oberfläche dazu prüfen die Browser-Tests `e2e/tests/automations.spec.mjs`,
`automations-limits.spec.mjs` und `automations-rules.spec.mjs` (mit derselben Uhr).

## Ausführen

Gegen eine Test-Installation mit Stub; braucht Node 22, `psql` und das Backend (`uv`).
`run-demo.sh` legt eine frische Datenbank an, migriert, startet Stub, API und drei Worker
als eigene Prozessgruppen (`setsid`) und ruft `demo_seed` und `demo-m7.mjs` auf. Pfade und
Ports sind die der Sandbox; `KEEP=1` lässt die Prozesse für Bildschirmfotos laufen.

```bash
DEMO_ADMIN_PASSWORD=… DEMO_PASSWORD=… ./run-demo.sh
```

#!/usr/bin/env node
// M7 demo against a running installation (an API and three workers of their own on one
// database) whose demo data came from `scripts.demo_seed` with the OpenAI stub as the
// model (HERD_DEMO_AI_*). Checks the demo's automations, then the acceptance: fifty
// automations due at once fire exactly once across three workers, also while one of
// them is killed; an event chain stops at depth 3; a heartbeat answering HEARTBEAT_OK
// stays silent; a budget stops a run and skips a term; the daily page review reminds
// once with three workers. Needs Node 22 and psql. Changes the installation: test
// installations only.
//   BASE=… STUB=… ADMIN_EMAIL=… ADMIN_PASSWORD=… DEMO_PASSWORD=… PSQL=postgresql://… \
//     WORKERS=http://127.0.0.1:9191,http://…,http://… KILL_WORKER='…' START_WORKER='…' \
//     CLOCK_FILE=/path/to/offset node demo-m7.mjs
// WORKERS: the internal ports of the three workers (their /metrics); KILL_WORKER kills
// the second one hard (SIGKILL), START_WORKER starts it again and waits for /ready.
// CLOCK_FILE: the offset file of the processes' clock (they run through
// `python -m tests.support.e2e_clock`); the demo moves it forward for quiet times and
// for the page review (31 days).
import { execFileSync, execSync } from "node:child_process";
import { renameSync, writeFileSync } from "node:fs";

const env = process.env;
for (const name of ["BASE", "STUB", "ADMIN_EMAIL", "ADMIN_PASSWORD", "DEMO_PASSWORD", "PSQL"])
  if (!env[name]) throw new Error(`${name} missing`);
for (const name of ["WORKERS", "KILL_WORKER", "START_WORKER", "CLOCK_FILE"])
  if (!env[name]) throw new Error(`${name} missing`);
const { BASE, STUB, PSQL, CLOCK_FILE } = env;
const WORKERS = env.WORKERS.split(",");
const N = 50;
const sleep = (ms) => new Promise((r) => setTimeout(r, ms));
let failed = false;
function check(what, ok, detail = "") {
  console.log(`${ok ? "OK  " : "FAIL"}  ${what}${detail ? ` (${detail})` : ""}`);
  if (!ok) failed = true;
}
const note = (text) => console.log(`      ${text}`);
const section = (title) => console.log(`== ${title}`);

// --- API, SQL, stub, metrics, clock --------------------------------------------------
const cookies = {};
async function api(who, method, path, body) {
  const r = await fetch(BASE + path, {
    method,
    headers: {
      "Content-Type": "application/json",
      "X-Requested-With": "herd",
      ...(cookies[who] ? { Cookie: cookies[who] } : {}),
    },
    body: body === undefined ? undefined : JSON.stringify(body),
  });
  const set = r.headers.getSetCookie?.() ?? [];
  if (set.length) cookies[who] = set.map((c) => c.split(";")[0]).join("; ");
  const text = await r.text();
  return { status: r.status, body: text ? JSON.parse(text) : null };
}
async function get(who, path) {
  const r = await api(who, "GET", path);
  if (r.status !== 200) throw new Error(`GET ${path}: ${r.status} ${JSON.stringify(r.body)}`);
  return r.body;
}
async function send(who, method, path, body) {
  const r = await api(who, method, path, body);
  if (r.status >= 300) throw new Error(`${method} ${path}: ${r.status} ${JSON.stringify(r.body)}`);
  return r.body;
}
const login = (who, email, password) => send(who, "POST", "/api/auth/login", { email, password });
const sql = (query) =>
  execFileSync("psql", [PSQL, "-tAF|", "-c", query], { encoding: "utf8" }).trim();
const ids = (list) => `ARRAY[${list.map((id) => `'${id}'`).join(",")}]::uuid[]`;
async function script(replies) {
  await fetch(`${STUB}/_stub/reset`, { method: "POST" });
  if (replies.length)
    await fetch(`${STUB}/_stub/script`, { method: "POST", body: JSON.stringify({ replies }) });
}
async function counter(worker, line) {
  const text = await (await fetch(`${worker}/metrics`)).text();
  const found = text.split("\n").find((l) => l.startsWith(`${line} `));
  return found ? Number(found.split(" ").at(-1)) : 0;
}
const counters = (line) => Promise.all(WORKERS.map((w) => counter(w, line).catch(() => null)));
let offset = 0;
function moveClock(seconds) {
  offset += seconds;
  writeFileSync(`${CLOCK_FILE}.next`, String(offset));
  renameSync(`${CLOCK_FILE}.next`, CLOCK_FILE);
}
async function until(what, probe, seconds = 90, every = 250) {
  const deadline = Date.now() + seconds * 1000;
  for (;;) {
    const value = await probe();
    if (value) return value;
    if (Date.now() > deadline) throw new Error(`timed out: ${what}`);
    await sleep(every);
  }
}
const run = (who, id) => get(who, `/api/runs/${id}`);
const firings = async (who, id) =>
  (await get(who, `/api/automations/${id}/firings?limit=100`)).items.reverse();
const runNow = (who, id) => send(who, "POST", `/api/automations/${id}/run`);
async function doneRun(who, id) {
  return until(`run ${id}`, async () => ((r) => r.state === "done" && r)(await run(who, id)));
}
async function agent(name, level, connectionId, responsible) {
  return send("admin", "POST", "/api/agents", {
    name,
    intro: `${name} hilft im Demo.`,
    instructions: "Antworte kurz auf Deutsch.",
    connection_id: connectionId,
    model: "gpt-6-luna",
    responsible_user_id: responsible,
    status: "active",
    level,
  });
}

// --- 2. Acceptance: N automations due at once, three workers -------------------------
const zaehler = await agent("Zähler", 1, connection.id, me.id);
async function wave(label, kill) {
  await script([]); // every run gets the stub's default answer
  const at = new Date(Math.ceil((Date.now() + 25_000) / 1000) * 1000);
  const made = [];
  for (let i = 0; i < N; i += 1) {
    const body = {
      agent_id: zaehler.id,
      place: { type: "dm" },
      instruction: `Zähle bis drei (${label}, ${i + 1}).`,
      schedule: { kind: "once", at: at.toISOString() },
    };
    made.push((await send("admin", "POST", "/api/automations", body)).id);
  }
  const STARTED = 'herd_automation_firings_total{outcome="started"}';
  const before = await counters(STARTED);
  note(`${N} automations made, all due at ${at.toISOString()}`);
  const count = () =>
    Number(sql(`SELECT count(*) FROM automation_firing WHERE automation_id = ANY(${ids(made)})`));
  let atKill = null;
  let ownAtKill = null;
  if (kill) {
    // Kill worker 2 as soon as it has fired a term of its own: in the middle of the burst.
    const own = async () => (await counter(WORKERS[1], STARTED)) - before[1];
    ownAtKill = await until(
      "worker 2's first term",
      async () => ((n) => n > 0 && n)(await own()),
      60,
      10,
    );
    execSync(env.KILL_WORKER, { stdio: "ignore" });
    atKill = count();
    note(
      `worker 2 killed (SIGKILL) after it had fired at least ${ownAtKill}; ${atKill} of ${N} terms fired then`,
    );
  }
  await until(`${N} terms`, async () => count() >= N, 90);
  const proof = sql(
    `SELECT count(*), count(DISTINCT automation_id), count(*) - count(DISTINCT (automation_id, due_at)),
            count(*) FILTER (WHERE outcome = 'started')
       FROM automation_firing WHERE automation_id = ANY(${ids(made)})`,
  );
  note(
    `SQL: SELECT count(*), count(DISTINCT automation_id), count(*) - count(DISTINCT (automation_id, due_at)), count(*) FILTER (WHERE outcome = 'started') FROM automation_firing WHERE automation_id = ANY(…) → ${proof}`,
  );
  const [terms, automations, doubles, started] = proof.split("|").map(Number);
  check(
    `${label}: exactly ${N} terms for ${N} automations, 0 doubles, all started`,
    terms === N && automations === N && doubles === 0 && started === N,
    proof,
  );
  if (kill) {
    execSync(env.START_WORKER, { stdio: "ignore" });
    note("worker 2 started again");
  }
  const runs = () =>
    sql(`SELECT count(*), count(DISTINCT automation_id), count(*) FILTER (WHERE state = 'done')
           FROM run WHERE automation_id = ANY(${ids(made)})`);
  await until(`${N} runs done`, async () => Number(runs().split("|")[2]) === N, 120);
  const [all, distinct, done] = runs().split("|").map(Number);
  note(
    `SQL: SELECT count(*), count(DISTINCT automation_id), count(*) FILTER (WHERE state = 'done') FROM run WHERE automation_id = ANY(…) → ${all}|${distinct}|${done}`,
  );
  check(
    `${label}: exactly one run per automation, all done`,
    all === N && distinct === N && done === N,
  );
  const after = await counters('herd_automation_firings_total{outcome="started"}');
  const shares = after.map((a, i) => (a === null || before[i] === null ? null : a - before[i]));
  return { shares, atKill, ownAtKill };
}

section(`2. Acceptance: ${N} automations due at once fire exactly once across three workers`);
const first = await wave("Welle 1", false);
note(`each worker's share (herd_automation_firings_total, started): ${first.shares.join(" / ")}`);
check(
  "The three shares add up to N",
  first.shares.reduce((s, v) => s + v, 0) === N,
