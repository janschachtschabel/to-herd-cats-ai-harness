# Demo M4: Tickets ohne Lärm in den Kanälen

Abnahme von Meilenstein 4 (Spezifikation 14): „Kanäle bleiben frei von Ticketmeldungen;
Systemmeldungen lassen sich im Thread ausblenden.“ Dazu die Unsichtbarkeit eines Tickets
über seine Nummer für eine Person ohne Zugang (Plan M4, Global Constraints und
Review-Fokus 1).

## Ablauf

1. Die Admin-Person legt Anna, Ben und Clara an (Systemrolle `member`), den
   Team-Bereich „Team Süd“ (Anna Moderatorin, Ben Autor, Clara nicht Mitglied) und den
   offenen Bereich „Haus“ mit dem Kanal `#flur`. Anna legt in Team Süd den Kanal `#sued`
   an und schreibt dort eine Nachricht, dazu eine Direktnachricht an Ben und eine Seite
   „Ablauf“.
2. Vorher wird für Anna, Ben und die Admin-Person jeder Kanal und jede Direktnachricht
   mit allen Nachrichten festgehalten (IDs, Antwortzahl, Bearbeitungszeit). Ben öffnet
   eine Live-Verbindung an **Knoten B**. Anna macht an **Knoten A** zehn Änderungen:
   ein Epic und ein Ticket anlegen, das Ticket Ben zuweisen, Status, Priorität,
   Fälligkeit, Titel, Beschreibung und übergeordnetes Ticket ändern, eine Seite
   verknüpfen; Ben kommentiert das Ticket. Sobald der Worker die neun Systemmeldungen
   des Tickets geschrieben hat, wird erneut festgehalten: Alles ist gleich. Bens
   Live-Verbindung bekam `message.created` nur für die Diskussionen der beiden Tickets,
   keines für einen Kanal oder eine Direktnachricht, dazu die Ticket-Ereignisse (nur
   Kennungen). Seine Ungelesen-Zähler zeigen nur Annas zwei Nachrichten von vorher.
3. Die Diskussion des Tickets enthält die neun Systemmeldungen und Bens Kommentar; mit
   `include_system=false` (dem Schalter „Systemmeldungen ausblenden“) nur den Kommentar.
   Systemmeldungen tragen einen Schlüssel und Kennungen, keinen Text, und niemand
   antwortet auf sie (422).
4. Clara fragt das Ticket über seine Nummer ab: 404 `ticket.not_found`, dieselbe Antwort
   und dieselbe Laufzeitklasse wie für eine Nummer, die es nie gab. Diskussion,
   verknüpfte Seiten und Ändern antworten ebenso; Suche nach dem Schlüssel, ihre
   Ticket-Liste und das Board des Bereichs nennen es nicht. Anna schreibt den Schlüssel
   in `#flur`: Clara liest ihn dort als Text (die Karte darunter lädt ihr Browser über
   dieselbe Abfrage, die 404 antwortet), Ben bekommt das Ticket für seine Karte.

Die Oberfläche dazu prüfen die Browser-Tests `e2e/tests/tickets-*.spec.mjs`: Anlegen
und Zuweisen mit der Aktivität der anderen Person, ein Zug auf dem Board per Tastatur
und Menü erscheint live bei der anderen Person, 409 aus einem veralteten Tab, Titel aus
zwei Tabs, Kommentar und Systemmeldungen mit „Systemmeldungen ausblenden“, die Karte im
Kanal für ein Mitglied und Text für eine Person ohne Zugang (die dazu „Dieses Ticket
gibt es nicht, oder du darfst es nicht sehen.“ sieht), eine Seitenverknüpfung von
beiden Seiten und der Abnahmesatz selbst (`tickets-quiet.spec.mjs`: nach zehn
Ticketänderungen hält kein Kanal und keine Direktnachricht eine neue Nachricht, über die
API und im Browser). Demodaten mit Tickets für eine Vorführung in der Oberfläche legt
`backend/scripts/demo_seed.py` an (siehe README, Entwicklung).

## Ausführen

Gegen eine laufende Installation mit zwei API-Knoten und einem Worker, etwa die
Compose-Überlagerung `deploy/compose/compose.nodes.yml` (`A` am Port
`HERD_HOST_PORT`, `B` am Port `HERD_HOST_PORT_B`). Mit nur einem Knoten (Rolle `all`)
zeigen `A` und `B` auf dieselbe Adresse. Braucht Node 22, sonst nichts. Das Skript legt
echte Personen, Bereiche, Tickets und Nachrichten an, also nur auf einer
Test-Installation laufen lassen; es kann mehrfach laufen (jeder Lauf hat eigene Namen).

```bash
A=http://127.0.0.1:8080 B=http://127.0.0.1:8081 ADMIN_EMAIL=admin@example.com ADMIN_PASSWORD=… \
  node demo-m4.mjs
```

#!/usr/bin/env node
// M4 demo against a running installation with two API nodes and a worker (or one node
// in role all: then A and B are the same address). Needs Node 22, nothing else.
// Creates real people, spaces, tickets and messages: test installations only.
//   A=http://127.0.0.1:8080 B=http://127.0.0.1:8081 ADMIN_EMAIL=admin@example.com \
//     ADMIN_PASSWORD=… node demo-m4.mjs
const { A, B, ADMIN_EMAIL, ADMIN_PASSWORD } = process.env;
if (!A || !B || !ADMIN_EMAIL || !ADMIN_PASSWORD) throw new Error("A, B, ADMIN_EMAIL, ADMIN_PASSWORD");
const sleep = (ms) => new Promise((r) => setTimeout(r, ms));
let failed = false;
function check(what, ok, detail = "") {
  console.log(`${ok ? "OK  " : "FAIL"}  ${what}${detail ? ` (${detail})` : ""}`);
  if (!ok) failed = true;
}

// --- API helper: one cookie per person, any node -------------------------------------
const cookies = {};
async function api(who, base, method, path, body) {
  const r = await fetch(base + path, {
    method,
    headers: { "Content-Type": "application/json", "X-Requested-With": "herd", Cookie: cookies[who] ?? "" },
    body: body === undefined ? undefined : JSON.stringify(body),
  });
  const text = await r.text();
  return { status: r.status, body: text ? JSON.parse(text) : null, headers: r.headers };
}
const ok = (r) => {
  if (r.status >= 300) throw new Error(`${r.status} ${JSON.stringify(r.body)}`);
  return r.body;
};
async function login(who, email, password) {
  const r = await api(who, A, "POST", "/api/auth/login", { email, password });
  if (r.status !== 200) throw new Error(`login ${who}: ${r.status}`);
  cookies[who] = r.headers.get("set-cookie").split(";")[0];
}

// --- A live stream (SSE) of one person on one node: collects events -----------------
function stream(who, base) {
  const events = [];
  const controller = new AbortController();
  const opened = (async () => {
    const r = await fetch(base + "/api/stream", { headers: { Cookie: cookies[who] }, signal: controller.signal });
    if (r.status !== 200) throw new Error(`stream ${who}: ${r.status}`);
    (async () => {
      const decoder = new TextDecoder();
      let buffer = "";
      try {
        for await (const chunk of r.body) {
          buffer += decoder.decode(chunk, { stream: true });
          let end;
          while ((end = buffer.indexOf("\n\n")) >= 0) {
            const frame = buffer.slice(0, end);
            buffer = buffer.slice(end + 2);
            const type = frame.match(/^event: (.*)$/m)?.[1];
            const data = frame.match(/^data: (.*)$/m)?.[1];
            if (type) events.push({ type, data: data ? JSON.parse(data) : {} });
          }
        }
      } catch {
        // aborted
      }
    })();
  })();
  return { events, opened, close: () => controller.abort() };
}

// Every channel and direct message a person sees, with its messages (ids, reply counts,
// edit times): what ticket changes must leave as it is.
async function snapshot(who) {
  const result = {};
  for (const list of ["/api/channels", "/api/dms"]) {
    let cursor = null;
    do {
      const page = ok(await api(who, B, "GET", `${list}?limit=100${cursor ? `&cursor=${encodeURIComponent(cursor)}` : ""}`));
      for (const c of page.items) {
        const messages = ok(await api(who, B, "GET", `/api/conversations/${c.id}/messages?limit=100`));
        result[c.id] = JSON.stringify([c.kind, messages.next_cursor, messages.items.map((m) => [m.id, m.reply_count, m.edited_at])]);
      }
      cursor = page.next_cursor;
    } while (cursor);
  }
  return result;
}
const same = (a, b) => JSON.stringify(a) === JSON.stringify(b);

const run = Date.now().toString(36);
const PASSWORD = "demo-password-4";
console.log(`== 1. Admin creates Anna, Ben and Clara, the team space Team Süd (${run}), channels, a DM`);

for (const [user, role] of [[anna, "moderator"], [ben, "editor"]]) {
  ok(await api("admin", A, "PUT", `/api/spaces/${space.id}/members`, { member_type: "user", member_id: user.id, role }));
}
const house = ok(await api("admin", A, "POST", "/api/spaces", { name: `Haus ${run}`, kind: "open" }));
for (const [who, user] of [["anna", anna], ["ben", ben], ["clara", clara]]) await login(who, user.email, PASSWORD);
const team = ok(await api("anna", A, "POST", `/api/spaces/${space.id}/channels`, { name: "sued" }));
const hall = ok(await api("admin", A, "POST", `/api/spaces/${house.id}/channels`, { name: "flur" }));
ok(await api("anna", A, "POST", `/api/conversations/${team.id}/messages`, { body_md: "Guten Morgen, Team Süd." }));
const dm = ok(await api("anna", A, "POST", "/api/dms", { user_ids: [ben.id] }));
ok(await api("anna", A, "POST", `/api/conversations/${dm.id}/messages`, { body_md: "Kurze Frage zum Plan." }));
const page = ok(await api("anna", A, "POST", `/api/spaces/${space.id}/pages`, { title: "Ablauf", content_md: "Erst planen." }));
const statuses = ok(await api("anna", A, "GET", `/api/spaces/${space.id}/ticket-statuses`)).items;
const status = (category) => statuses.find((s) => s.category === category).id;

console.log("== 2. Ten ticket changes on node A: channels and direct messages stay as they were");
const before = { anna: await snapshot("anna"), ben: await snapshot("ben"), admin: await snapshot("admin") };
const benLive = stream("ben", B);
await benLive.opened;
const epic = ok(await api("anna", A, "POST", `/api/spaces/${space.id}/tickets`, { title: "Umzug", kind: "epic" }));
let ticket = ok(await api("anna", A, "POST", `/api/spaces/${space.id}/tickets`, { title: "Kisten packen" }));
const key = ticket.key;
const change = async (fields) => {
  ticket = ok(await api("anna", A, "PATCH", `/api/tickets/${ticket.number}`, { ...fields, version: ticket.version }));

await change({ title: `Kisten packen und beschriften (${key})` });
await change({ description_md: `Siehe #sued und ${key}.` });
await change({ parent_id: epic.id });
ok(await api("anna", A, "PUT", `/api/tickets/${ticket.number}/pages/${page.id}`));
const thread = ok(await api("ben", B, "GET", `/api/tickets/${ticket.number}/thread`));

// Wait for the worker: one system entry per change in the ticket's thread.
const expected = ["ticket.created", "ticket.assigned", "ticket.status_changed", "ticket.priority_changed",
  "ticket.due_changed", "ticket.title_changed", "ticket.description_changed", "ticket.parent_changed",
  "ticket.page_linked"];
let keys = [];
for (let i = 0; i < 200; i++) {
  const page = ok(await api("ben", B, "GET", `/api/conversations/${thread.id}/messages?limit=100`));
  keys = page.items.filter((m) => m.kind === "system").map((m) => m.system.key).reverse();

}
check("The worker wrote one system entry per change into the ticket's thread", same(keys, expected), keys.join(", "));
await sleep(1000); // the live events of the last entries
const after = { anna: await snapshot("anna"), ben: await snapshot("ben"), admin: await snapshot("admin") };
const conversations = new Set([...Object.keys(before.anna), ...Object.keys(before.ben), ...Object.keys(before.admin)]);
check("API: every channel and DM of Anna, Ben and the admin unchanged", same(before, after),
  `${conversations.size} conversations compared`);
const epicThread = ok(await api("ben", B, "GET", `/api/tickets/${epic.number}/thread`));
const created = benLive.events.filter((e) => e.type === "message.created");
const inThreads = created.filter((e) => [thread.id, epicThread.id].includes(e.data.conversation_id));
const inChannels = created.filter((e) => conversations.has(e.data.conversation_id));
check("Ben's live stream: message.created only in the two tickets' threads, none in a channel or DM",
  created.length > 0 && inThreads.length === created.length && inChannels.length === 0,
  `${inThreads.length} in the ticket threads, ${inChannels.length} in channels or DMs`);
const ticketEvents = benLive.events.filter((e) => e.type.startsWith("ticket."));
check("Ben's live stream got the ticket events (ids only)", ticketEvents.length >= 10 &&
  ticketEvents.every((e) => Object.keys(e.data).sort().join() === "conversation_id,message_id,parent_id,ticket_id"),
  `${ticketEvents.length} ticket.created/updated`);
const unread = ok(await api("ben", B, "GET", "/api/conversations/unread?limit=100")).items;
check("Ben's unread: #sued nothing new, the DM only Anna's question",
  !unread.some((u) => u.conversation_id === team.id && u.unread > 1) &&
  (unread.find((u) => u.conversation_id === dm.id)?.unread ?? 0) === 1, JSON.stringify(unread.filter((u) => u.conversation_id !== thread.id)));
benLive.close();

console.log("== 3. System entries can be hidden in the thread");
const all = ok(await api("ben", B, "GET", `/api/conversations/${thread.id}/messages?limit=100`)).items;
const human = ok(await api("ben", B, "GET", `/api/conversations/${thread.id}/messages?limit=100&include_system=false`)).items;
check("With system entries: 9 entries and Ben's comment", all.length === 10 && all.filter((m) => m.kind === "system").length === 9);
check("Without (include_system=false): only Ben's comment", human.length === 1 && human[0].id === comment.id);
check("A system entry carries a key and ids, no text", all.every((m) => m.kind !== "system" || (m.author === null && m.system.key.startsWith("ticket."))));
const reply = await api("anna", A, "POST", `/api/conversations/${thread.id}/messages`, { body_md: "Antwort", parent_id: all.find((m) => m.kind === "system").id });
check("Nobody replies to a system entry: 422", reply.status === 422, reply.body?.error?.code);

console.log("== 4. Clara (not in Team Süd) cannot see the ticket, not even by its number");
const hidden = await api("clara", B, "GET", `/api/tickets/${ticket.number}`);
const free = await api("clara", B, "GET", `/api/tickets/${ticket.number + 100000}`);
check("Clara: GET /api/tickets/<number> 404 ticket.not_found", hidden.status === 404 && hidden.body.error.code === "ticket.not_found");
check("The same answer as for a number nobody has", free.status === hidden.status && free.body.error.code === hidden.body.error.code &&
  same(Object.keys(free.body.error).sort(), Object.keys(hidden.body.error).sort()));
const timing = async (number) => {
  const ms = [];
  for (let i = 0; i < 30; i++) {
    const t = performance.now();
    await api("clara", B, "GET", `/api/tickets/${number}`);
    ms.push(performance.now() - t);
  }
  return ms.sort((a, b) => a - b)[15];
};
const [tHidden, tFree] = [await timing(ticket.number), await timing(ticket.number + 100000)];
check("Same time class (median of 30)", Math.abs(tHidden - tFree) < 10, `hidden ${tHidden.toFixed(1)} ms, free ${tFree.toFixed(1)} ms`);
for (const [what, path] of [
  ["thread", `/api/tickets/${ticket.number}/thread`],
  ["linked pages", `/api/tickets/${ticket.number}/pages`],
]) {
  const r = await api("clara", B, "GET", path);
  check(`Clara: the ticket's ${what} 404`, r.status === 404, r.body?.error?.code);
}
const patch = await api("clara", B, "PATCH", `/api/tickets/${ticket.number}`, { title: "x", version: ticket.version });
check("Clara: changing it 404 too", patch.status === 404, patch.body?.error?.code);
const search = ok(await api("clara", B, "GET", `/api/search?q=${encodeURIComponent(key)}&types=ticket`));
const list = ok(await api("clara", B, "GET", "/api/tickets?limit=100"));
check("Clara: neither search for the key nor her ticket list finds it", search.items.length === 0 && !list.items.some((t) => t.id === ticket.id));
const board = await api("clara", B, "GET", `/api/spaces/${space.id}/board`);
check("Clara: the space's board 404", board.status === 404, board.body?.error?.code);
ok(await api("anna", A, "POST", `/api/conversations/${hall.id}/messages`, { body_md: `Bitte ${key} ansehen.` }));
const shown = ok(await api("clara", B, "GET", `/api/conversations/${hall.id}/messages`)).items;
check("Clara reads the key in #flur (an open space) as plain text; the card's GET answers 404",
  shown.some((m) => m.body_md.includes(key)) && hidden.status === 404);
const forBen = await api("ben", B, "GET", `/api/tickets/${ticket.number}`);
check("Ben (in the space) gets the ticket for the card", forBen.status === 200 && forBen.body.key === key);

console.log(failed ? "DEMO FAILED" : "DEMO OK");
process.exit(failed ? 1 : 0);
