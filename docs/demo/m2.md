# Demo M2: Wiki mit Live-Bearbeitung

Abnahme von Meilenstein 2 (Spezifikation 14): Zwei Browser bearbeiten gleichzeitig; das
Speichern im Markdown-Modus beendet die Live-Sitzung sauber; die Suche findet nur
Sichtbares.

## Ablauf

1. Die Admin-Person legt Anna, Ben und Clara an (Systemrolle `member`) und zwei
   Team-Bereiche, „Team Nord“ und „Team Süd“. In Team Nord sind Anna und Ben Autoren
   (`editor`), Clara ist Leserin (`viewer`); in Team Süd ist nur die Admin-Person. Team
   Nord bekommt die veröffentlichte Seite „Protokoll“ und den Entwurf „Planung“, Team Süd
   die veröffentlichte Seite „Strategie“. „Planung“ und „Strategie“ enthalten das
   Stichwort „Kranichflug“.
2. Anna und Ben öffnen „Protokoll“ je in ihrem eigenen Browser mit „Gemeinsam
   bearbeiten“. Anna sieht Ben als anwesend. Anna tippt eine Zeile, Ben sieht sie live;
   Ben tippt eine Zeile, Anna sieht sie live. Beides landet gespeichert in der Seite, als
   Version mit der Quelle `collab`.
3. Clara bekommt die Schaltfläche „Gemeinsam bearbeiten“ nicht. Anna speichert in einem
   zweiten Tab im Markdown-Editor eine Änderung. Die Generation der Seite steigt; beide
   Live-Editoren melden „Die Seite wurde außerhalb der Live-Sitzung geändert“ und zeigen
   den neuen Stand. 12 Sekunden später (länger als das Speicherintervall der
   Live-Sitzung) ist die Seite noch genau der Markdown-Stand: Kein alter Live-Zustand hat
   ihn überschrieben. Danach tippt Ben weiter; das wird in der neuen Sitzung auf den
   Markdown-Stand gespeichert.
4. Suche nach „Kranichflug“: Ben (Autor in Team Nord) findet den Entwurf „Planung“,
   nicht „Strategie“ aus Team Süd. Clara (Leserin) findet nichts, weder den Entwurf noch
   Team Süd, und die Antwort nennt keinen der verborgenen Titel. Die Admin-Person findet
   beide. Claras Suchpalette (Strg+K) zeigt „Keine Treffer.“

## Ausführen

Gegen eine laufende Installation mit Live-Bearbeitung (Compose-Referenz mit
`HERD_INTERNAL_TOKEN`, siehe README). Braucht Node 22 und Playwright mit Chromium;
Playwright ist keine Abhängigkeit des Projekts und muss vorhanden sein. Das Skript legt
echte Personen, Bereiche und Seiten an, also nur auf einer Test-Installation laufen
lassen. Mit `SHOTS=/ein/verzeichnis` legt es dazu Bildschirmfotos ab.

```bash
BASE=http://127.0.0.1:8080 ADMIN_EMAIL=admin@example.com ADMIN_PASSWORD=… node demo-m2.mjs
```

```js
#!/usr/bin/env node
// M2 demo against a running installation (compose reference). Needs Node 22 and
// Playwright with Chromium (`npm i -g playwright && npx playwright install chromium`;
// not a project dependency). Creates real people, spaces and pages: test installs only.
//   BASE=http://127.0.0.1:8080 ADMIN_EMAIL=admin@example.com ADMIN_PASSWORD=… node demo-m2.mjs
import { createRequire } from "node:module";
const { chromium } = createRequire(import.meta.url)("playwright");

const { BASE, ADMIN_EMAIL, ADMIN_PASSWORD, SHOTS } = process.env;
if (!BASE || !ADMIN_EMAIL || !ADMIN_PASSWORD) throw new Error("BASE, ADMIN_EMAIL, ADMIN_PASSWORD");
const sleep = (ms) => new Promise((r) => setTimeout(r, ms));
let failed = false;
function check(what, expected, actual) {
  const ok = JSON.stringify(expected) === JSON.stringify(actual);
  console.log(`${ok ? "OK  " : "FAIL"}  ${what}${ok ? "" : ` (expected ${JSON.stringify(expected)}, got ${JSON.stringify(actual)})`}`);
  if (!ok) failed = true;
}
async function until(what, fn, ms = 20000) {
  const end = Date.now() + ms;
  while (Date.now() < end) { if (await fn()) return true; await sleep(200); }
  throw new Error(`timed out: ${what}`);
}

// --- API helper with a cookie per person ------------------------------------------
const cookies = {};
async function api(who, method, path, body) {
  const r = await fetch(BASE + path, {
    method,
    headers: { "Content-Type": "application/json", "X-Requested-With": "herd", Cookie: cookies[who] ?? "" },
    body: body === undefined ? undefined : JSON.stringify(body),
  });
  const text = await r.text();
  return { status: r.status, body: text ? JSON.parse(text) : null, headers: r.headers };
}
async function login(who, email, password) {
  const r = await api(who, "POST", "/api/auth/login", { email, password });
  if (r.status !== 200) throw new Error(`login ${who}: ${r.status}`);
  cookies[who] = r.headers.get("set-cookie").split(";")[0];
}
const ok = (r) => { if (r.status >= 300) throw new Error(`${r.status} ${JSON.stringify(r.body)}`); return r.body; };

console.log("== 1. The admin creates Anna, Ben and Clara, Team Nord and Team Süd, and pages");
await login("admin", ADMIN_EMAIL, ADMIN_PASSWORD);
const person = async (name, email) =>
  ok(await api("admin", "POST", "/api/admin/users", { name, email, password: "demo-password-2", system_role: "member" }));
const anna = await person("Anna Nord", "anna2@example.com");
const ben = await person("Ben Nord", "ben2@example.com");
const clara = await person("Clara Gast", "clara2@example.com");
const nord = ok(await api("admin", "POST", "/api/spaces", { name: "Team Nord", kind: "team" }));
const sued = ok(await api("admin", "POST", "/api/spaces", { name: "Team Süd", kind: "team" }));
const member = (space, user, role) =>
  api("admin", "PUT", `/api/spaces/${space.id}/members`, { member_type: "user", member_id: user.id, role });
await member(nord, anna, "editor");
await member(nord, ben, "editor");
await member(nord, clara, "viewer");
const page = async (space, title, content_md, publish = true) => {
  const p = ok(await api("admin", "POST", `/api/spaces/${space.id}/pages`, { title, content_md }));
  return publish ? ok(await api("admin", "POST", `/api/pages/${p.id}/publish`, { version: p.version })) : p;
};
const protokoll = await page(nord, "Protokoll", "# Protokoll\n\nWochentreffen Team Nord.");
await page(nord, "Planung", "# Planung\n\nDas Stichwort Kranichflug steht in einem Entwurf.", false);
await page(sued, "Strategie", "# Strategie\n\nDas Stichwort Kranichflug steht auch im Team Süd.");
console.log(`Team Nord ${nord.id}, Team Süd ${sued.id}, Protokoll ${protokoll.id}`);

console.log("== 2. Anna and Ben edit the page live, each in their own browser");
const browser = await chromium.launch();
const problems = [];
async function open(who, email) {
  const ctx = await browser.newContext({ viewport: { width: 1280, height: 800 }, deviceScaleFactor: 2, locale: "de-DE" });
  const tab = await ctx.newPage();
  tab.on("pageerror", (e) => problems.push(`${who}: ${e.message}`));
  await tab.goto(`${BASE}/login`);
  await tab.getByLabel("E-Mail-Adresse").fill(email);
  await tab.getByLabel("Passwort").fill("demo-password-2");
  await tab.getByRole("button", { name: "Anmelden" }).click();
  await tab.waitForURL(/\/spaces/);
  return tab;
}
const pageUrl = `${BASE}/spaces/${nord.id}/p/${protokoll.path}`;
const A = await open("anna", "anna2@example.com");
const B = await open("ben", "ben2@example.com");
for (const tab of [A, B]) {
  await tab.goto(pageUrl);
  await tab.getByRole("link", { name: "Gemeinsam bearbeiten" }).click();
  await tab.getByText("Synchronisiert").waitFor();
}
const editor = (tab) => tab.getByRole("textbox", { name: "Inhalt von „Protokoll“" });
async function typeAtEnd(tab, text) {
  await editor(tab).click();
  await sleep(200); // ProseMirror reads the click's selection after the event
  await tab.keyboard.press("Control+End");
  await tab.keyboard.press("Enter");
  await tab.keyboard.type(text, { delay: 20 });
}
check("Anna sees Ben as present", true, await A.getByText("Ben Nord").first().isVisible());
await typeAtEnd(A, "Anna: Punkt eins.");
await until("Ben sees Anna's line", async () => (await editor(B).innerText()).includes("Anna: Punkt eins."));
check("Ben sees Anna's line live", true, (await editor(B).innerText()).includes("Anna: Punkt eins."));
await typeAtEnd(B, "Ben: Punkt zwei.");
await until("Anna sees Ben's line", async () => (await editor(A).innerText()).includes("Ben: Punkt zwei."));
check("Anna sees Ben's line live", true, (await editor(A).innerText()).includes("Ben: Punkt zwei."));
await login("anna", "anna2@example.com", "demo-password-2");
await until("the live edits are saved", async () => {
  const md = (await api("anna", "GET", `/api/pages/${protokoll.id}`)).body.content_md;
  return md.includes("Anna: Punkt eins.") && md.includes("Ben: Punkt zwei.");
});
const live = (await api("anna", "GET", `/api/pages/${protokoll.id}`)).body;
console.log("saved Markdown:\n" + live.content_md.replace(/^/gm, "    "));
const sources = (await api("anna", "GET", `/api/pages/${protokoll.id}/versions`)).body.items.map((v) => v.source);
check("a version with source collab exists", true, sources.includes("collab"));
if (SHOTS) { await A.screenshot({ path: `${SHOTS}/24-demo-live-anna.png` }); await B.screenshot({ path: `${SHOTS}/25-demo-live-ben.png` }); }

console.log("== 3. Clara cannot edit; Anna saves in the Markdown editor, which ends the live session");
const C = await open("clara", "clara2@example.com");
await C.goto(pageUrl);
await C.getByRole("heading", { level: 2, name: "Protokoll" }).waitFor();
check("Clara (viewer) gets no 'Gemeinsam bearbeiten'", 0, await C.getByRole("link", { name: "Gemeinsam bearbeiten" }).count());
const M = await A.context().newPage(); // Anna's second tab
await M.goto(`${pageUrl}?view=edit`);
const md = M.getByLabel("Markdown");
await md.waitFor();
await md.fill((await md.inputValue()) + "\n\nIm Markdown-Modus beschlossen.");
await M.getByRole("button", { name: "Speichern" }).click();
await until("Markdown save done", async () =>
  (await api("anna", "GET", `/api/pages/${protokoll.id}`)).body.content_md.endsWith("Im Markdown-Modus beschlossen."));
const saved = (await api("anna", "GET", `/api/pages/${protokoll.id}`)).body;
check("the generation went up", live.collab_generation + 1, saved.collab_generation);
for (const [who, tab] of [["Anna", A], ["Ben", B]]) {
  await tab.getByText("Die Seite wurde außerhalb der Live-Sitzung geändert").waitFor();
  await until(`${who}'s editor shows the Markdown save`, async () =>
    (await editor(tab).innerText()).includes("Im Markdown-Modus beschlossen."));
  check(`${who} is told and sees the new state`, true, (await editor(tab).innerText()).includes("Im Markdown-Modus beschlossen."));
}
if (SHOTS) await B.screenshot({ path: `${SHOTS}/26-demo-live-ended-by-markdown-save.png` });
await sleep(12000); // longer than the live save interval (≤ 10 s)
check("no old live state overwrote the Markdown save (12 s later)", saved.content_md,
  (await api("anna", "GET", `/api/pages/${protokoll.id}`)).body.content_md);
await typeAtEnd(B, "Ben: weiter in der neuen Sitzung.");
await until("the new live session saves", async () =>
  (await api("anna", "GET", `/api/pages/${protokoll.id}`)).body.content_md.includes("Ben: weiter in der neuen Sitzung."));
const final = (await api("anna", "GET", `/api/pages/${protokoll.id}`)).body.content_md;
check("the new live session saves on top of the Markdown save", true,
  final.includes("Im Markdown-Modus beschlossen.") && final.endsWith("Ben: weiter in der neuen Sitzung."));

console.log("== 4. Search finds only what each person may see");
await login("ben", "ben2@example.com", "demo-password-2");
await login("clara", "clara2@example.com", "demo-password-2");
const hits = async (who) => (await api(who, "GET", "/api/search?q=Kranichflug")).body.items.map((h) => h.title).sort();
check("Ben (editor in Nord) finds the Nord draft, not Team Süd", ["Planung"], await hits("ben"));
check("Clara (viewer in Nord) finds nothing: no drafts, no Team Süd", [], await hits("clara"));
check("the admin finds both", ["Planung", "Strategie"], await hits("admin"));
const raw = JSON.stringify((await api("clara", "GET", "/api/search?q=Kranichflug")).body);
check("Clara's answer names nothing hidden", false, /Strategie|Süd|Planung/.test(raw));
await C.keyboard.press("Control+k");
await C.getByRole("combobox", { name: "Suchbegriff" }).fill("Kranichflug");
await C.getByText("Keine Treffer.").waitFor();
check("Clara's search palette shows no hits", true, await C.getByText("Keine Treffer.").isVisible());
if (SHOTS) await C.screenshot({ path: `${SHOTS}/27-demo-search-viewer-no-hits.png` });

await browser.close();
check("no page errors in the browsers", [], problems);
console.log(failed ? "DEMO FAILED" : "DEMO OK");
process.exit(failed ? 1 : 0);
```

Die App-Logs des Laufs (246 Zeilen) enthalten keines der Passwörter, nicht das interne
Token und kein Sitzungs-Cookie, und keine Zeile auf `WARNING` oder `ERROR`. Der
Collab-Prozess protokolliert das Ende der ersten Generation (`live document dropped`,
`reason: generation_ended`). Ein Lauf davor auf einer eigenen frischen Installation
(gleiches Skript, nur die vorletzte Prüfung von Schritt 3 war schwächer) endete ebenso
mit `DEMO OK`.

Bildschirmfotos des Laufs (nicht im Repository): Annas und Bens Live-Editor mit beiden
Zeilen und dem Kürzel der anderen Person; Bens Editor nach dem Speichern im
Markdown-Modus mit dem Hinweis, dem neuen Stand und „Meinen Text als Markdown
kopieren“; Claras Suchpalette mit „Keine Treffer.“

**Abnahme: erfüllt.** Jeder Schritt verlief wie beschrieben.

Auffällig, aber nicht Teil der Abnahme:

- Bis offene Live-Editoren das Ende der Generation bemerken, vergehen bis zu 5 s: Der
  Collab-Prozess prüft Generation und Rechte alle 5 s, oder früher beim nächsten
  Speicherversuch. Mit zehn Live-Editoren gemessen: 0,3 s und 4,4 s in zwei Läufen
  (siehe [Steckbrief](../STECKBRIEF.md#gemessen-live-bearbeitung-mit-10-editoren)). Gespeichert
  wird in dieser Zeit nichts Altes: Die API lehnt den alten Stand ab.
- Ben bekommt nach dem Speichern im Markdown-Modus „Meinen Text als Markdown kopieren“
  angeboten, obwohl seine Zeile schon gespeichert war: Verglichen wird sein alter
  Live-Stand mit dem neuen Seitenstand, und dem alten fehlte die Markdown-Zeile. Das
  Angebot ist harmlos, aber hier überflüssig.
