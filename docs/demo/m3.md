# Demo M3: Nachrichten über zwei Knoten

Abnahme von Meilenstein 3 (Spezifikation 14): „Eine Nachricht auf Knoten A erscheint
live auf Knoten B; eine Erwähnung erzeugt eine Aktivität.“ Dazu der Entzug der
Mitgliedschaft bei offener Live-Verbindung und die Einsicht in eine Direktnachricht mit
Begründung und Audit-Eintrag (Plan M3, Task 12).

## Ablauf

1. Die Admin-Person legt Anna und Ben an (Systemrolle `member`) und den Team-Bereich
   „Team Nord“ (Anna Moderatorin, Ben Autor); Anna legt den Kanal `#kranich` an.
2. Ben und Anna öffnen je eine Live-Verbindung (`GET /api/stream`) an **Knoten B**.
   Anna schreibt an **Knoten A** eine Nachricht, die Ben erwähnt. Bens Verbindung an
   Knoten B bekommt `message.created` mit der ID dieser Nachricht und
   `notification.created`; seine Aktivität (abgefragt an Knoten B) enthält die
   Erwähnung, der Zähler steht auf 1. Anna bekommt die Nachricht auch, aber keine
   Benachrichtigung.
3. Die Admin-Person nimmt Ben aus dem Bereich, während seine Verbindung offen ist. Annas
   nächste Nachricht kommt bei Anna live an, bei Ben nicht (auch 2 s danach nicht). Ben
   bekommt für den Kanal 404 `conversation.not_found`.
4. Ben schreibt Anna eine Direktnachricht. Die Admin-Person findet sie über die
   Einsicht, wird ohne echte Begründung abgewiesen (422), bekommt mit Begründung eine
   Einsicht für 60 Minuten und liest die Nachricht. Schreiben kann sie dort nicht (404,
   als gäbe es das Gespräch nicht), und ihre Suche findet die Nachricht nicht. Das Audit
   enthält `dm.admin_lookup` und `dm.admin_access` mit der Begründung; Anna sieht im
   Gespräch, dass die Verwaltung eingesehen hat.

Die Oberfläche dazu prüfen die Browser-Tests in `e2e/tests/messaging-*.spec.mjs` (zwei
Personen im Kanal live, Reaktion, Thread, Erwähnung in der Aktivität, Suche,
Seiten-Diskussion mit Systemmeldung, Einsicht nur lesend mit Begründung). Demodaten für
eine Vorführung in der Oberfläche legt `backend/scripts/demo_seed.py` an (siehe README,
Entwicklung).

## Ausführen

Gegen eine laufende Installation mit zwei API-Knoten und einem Worker, etwa die
Compose-Überlagerung `deploy/compose/compose.nodes.yml` (`A` am Port
`HERD_HOST_PORT`, `B` am Port `HERD_HOST_PORT_B`). Mit nur einem Knoten (Rolle `all`)
zeigen `A` und `B` auf dieselbe Adresse; dann prüft Schritt 2 nur die Zustellung
innerhalb eines Prozesses. Braucht Node 22, sonst nichts. Das Skript legt echte
Personen, einen Bereich und Nachrichten an, also nur auf einer Test-Installation laufen
lassen; es kann mehrfach laufen (jeder Lauf hat eigene Namen).

```bash
A=http://127.0.0.1:8080 B=http://127.0.0.1:8081 ADMIN_EMAIL=admin@example.com ADMIN_PASSWORD=… \
  node demo-m3.mjs
```

```js
#!/usr/bin/env node
// M3 demo against a running installation with two API nodes and a worker (or one node
// in role all: then A and B are the same address). Needs Node 22, nothing else.
// Creates real people, a space and messages: test installations only.
//   A=http://127.0.0.1:8080 B=http://127.0.0.1:8081 ADMIN_EMAIL=admin@example.com \
//     ADMIN_PASSWORD=… node demo-m3.mjs
const { A, B, ADMIN_EMAIL, ADMIN_PASSWORD } = process.env;
if (!A || !B || !ADMIN_EMAIL || !ADMIN_PASSWORD) throw new Error("A, B, ADMIN_EMAIL, ADMIN_PASSWORD");
const sleep = (ms) => new Promise((r) => setTimeout(r, ms));
let failed = false;
function check(what, ok, detail = "") {
  console.log(`${ok ? "OK  " : "FAIL"}  ${what}${detail ? ` (${detail})` : ""}`);
  if (!ok) failed = true;
}

// --- API helper: one cookie per person, any node -------------------------------------
const cookies = {};
async function api(who, base, method, path, body) {
  const r = await fetch(base + path, {
    method,
    headers: { "Content-Type": "application/json", "X-Requested-With": "herd", Cookie: cookies[who] ?? "" },
    body: body === undefined ? undefined : JSON.stringify(body),
  });
  const text = await r.text();
  return { status: r.status, body: text ? JSON.parse(text) : null, headers: r.headers };
}
const ok = (r) => {
  if (r.status >= 300) throw new Error(`${r.status} ${JSON.stringify(r.body)}`);
  return r.body;
};
async function login(who, email, password) {
  const r = await api(who, A, "POST", "/api/auth/login", { email, password });
  if (r.status !== 200) throw new Error(`login ${who}: ${r.status}`);
  cookies[who] = r.headers.get("set-cookie").split(";")[0];
}

// --- A live stream (SSE) of one person on one node: collects events with arrival time
function stream(who, base) {
  const events = [];
  const controller = new AbortController();
  const opened = (async () => {
    const r = await fetch(base + "/api/stream", { headers: { Cookie: cookies[who] }, signal: controller.signal });
    if (r.status !== 200) throw new Error(`stream ${who}: ${r.status}`);
    (async () => {
      const decoder = new TextDecoder();
      let buffer = "";
      try {
        for await (const chunk of r.body) {
          buffer += decoder.decode(chunk, { stream: true });
          let end;
          while ((end = buffer.indexOf("\n\n")) >= 0) {
            const frame = buffer.slice(0, end);
            buffer = buffer.slice(end + 2);
            const type = frame.match(/^event: (.*)$/m)?.[1];
            const data = frame.match(/^data: (.*)$/m)?.[1];
            if (type) events.push({ type, data: data ? JSON.parse(data) : {}, at: performance.now() });
          }
        }
      } catch {
        // aborted
      }
    })();
  })();
  return {
    events,
    opened,
    close: () => controller.abort(),
    async wait(pred, ms = 10000) {
      const end = Date.now() + ms;
      while (Date.now() < end) {
        const found = events.find(pred);
        if (found) return found;
        await sleep(25);
      }
      return null;
    },
  };
}
const created = (id) => (e) => e.type === "message.created" && e.data.message_id === id;
const post = (who, base, conversation, body_md, mentions = []) =>
  api(who, base, "POST", `/api/conversations/${conversation}/messages`, { body_md, mentions });

const run = Date.now().toString(36);
console.log(`== 1. Admin creates Anna and Ben, the team space Team Nord (${run}) and #kranich`);
await login("admin", ADMIN_EMAIL, ADMIN_PASSWORD);
const person = async (name, email) =>
  ok(await api("admin", A, "POST", "/api/admin/users", { name, email, password: "demo-password-3", system_role: "member" }));
const anna = await person("Anna Nord", `anna-${run}@demo.example`);
const ben = await person("Ben Berg", `ben-${run}@demo.example`);
const space = ok(await api("admin", A, "POST", "/api/spaces", { name: `Team Nord ${run}`, kind: "team" }));
for (const [user, role] of [[anna, "moderator"], [ben, "editor"]]) {
  ok(await api("admin", A, "PUT", `/api/spaces/${space.id}/members`, { member_type: "user", member_id: user.id, role }));
}
await login("anna", anna.email, "demo-password-3");
await login("ben", ben.email, "demo-password-3");
const channel = ok(await api("anna", A, "POST", `/api/spaces/${space.id}/channels`, { name: "kranich" }));

console.log("== 2. A message written on node A arrives live on node B; a mention makes activity");
const benLive = stream("ben", B);
const annaLive = stream("anna", B);
await Promise.all([benLive.opened, annaLive.opened]);
const sent = performance.now();
const hello = ok(await post("anna", A, channel.id, `@[Ben Berg](user:${ben.id}) Kick-off am Montag?`, [ben.id]));
const arrived = await benLive.wait(created(hello.id));
check("Ben's stream on node B gets message.created of Anna's message from node A", !!arrived,
  arrived ? `${Math.round(arrived.at - sent)} ms after sending` : "nothing within 10 s");
const told = await benLive.wait((e) => e.type === "notification.created" && e.data.message_id === hello.id);
check("Ben's stream gets notification.created for the mention", !!told);
const activity = ok(await api("ben", B, "GET", "/api/activity"));
check("Ben's activity (node B) lists the mention", activity.items.some((n) => n.reason === "mention" && n.message_id === hello.id));
const count = ok(await api("ben", B, "GET", "/api/activity/count"));
check("Ben's activity counter", count.unread === 1, JSON.stringify(count));
check("Anna's stream on node B gets the message too, but no notification",
  !!(await annaLive.wait(created(hello.id))) && !annaLive.events.some((e) => e.type === "notification.created"));

console.log("== 3. Ben loses his membership while his stream is open");
ok(await api("admin", A, "DELETE", `/api/spaces/${space.id}/members/user/${ben.id}`));
const after = ok(await post("anna", A, channel.id, "Nur noch für das Team."));
check("Anna (still a member) gets the next message live", !!(await annaLive.wait(created(after.id))));
await sleep(2000);
check("Ben's open stream does not get it (waited 2 s after Anna's arrived)", !benLive.events.some(created(after.id)));
const gone = await api("ben", B, "GET", `/api/conversations/${channel.id}`);
check("Ben opening the channel: 404 conversation.not_found", gone.status === 404 && gone.body.error.code === "conversation.not_found");
benLive.close();
annaLive.close();

console.log("== 4. The admin inspects a direct message: reason, audit, notice");
const dm = ok(await api("ben", A, "POST", "/api/dms", { user_ids: [anna.id] }));
ok(await post("ben", A, dm.id, "Unter uns: das Budget reicht nicht."));
const found = ok(await api("admin", A, "GET", `/api/admin/dm-inspect?user_id=${ben.id}`));
check("The admin finds Ben's direct message", found.items.some((d) => d.conversation_id === dm.id));
const noReason = await api("admin", A, "POST", "/api/admin/dm-inspect", { conversation_id: dm.id, reason: "kurz" });
check("Without a real reason: 422", noReason.status === 422, noReason.body?.error?.code);
const reason = "Hinweis auf Mobbing, Fall 2026-17";
const grant = ok(await api("admin", A, "POST", "/api/admin/dm-inspect", { conversation_id: dm.id, reason }));
const minutes = Math.round((Date.parse(grant.expires_at) - Date.parse(grant.granted_at)) / 60000);
check("Inspection granted for 60 minutes", minutes === 60, `${minutes} min`);
const read = ok(await api("admin", A, "GET", `/api/admin/dm-inspect/${grant.id}/messages`));
check("The admin reads the messages", read.items.some((m) => m.body_md.includes("Budget")));
const write = await post("admin", A, dm.id, "Ich lese mit.");
check("The admin cannot write in it (404, as if it did not exist)", write.status === 404, write.body?.error?.code);
const audit = ok(await api("admin", A, "GET", "/api/admin/audit?action=dm.admin_access"));
const entry = audit.items.find((e) => e.target_id === dm.id);
check("Audit: dm.admin_access with the reason", entry?.details?.reason === reason);
const lookup = ok(await api("admin", A, "GET", "/api/admin/audit?action=dm.admin_lookup"));
check("Audit: dm.admin_lookup for the list of Ben's direct messages", lookup.items.some((e) => e.target_id === ben.id));
const seen = ok(await api("anna", B, "GET", `/api/conversations/${dm.id}`));
check("Anna sees that the administration looked in", seen.inspections.length === 1, JSON.stringify(seen.inspections[0]));
const search = ok(await api("admin", A, "GET", "/api/search?q=Budget&types=message"));
check("The admin's search does not find the inspected message", search.items.length === 0);

console.log(failed ? "DEMO FAILED" : "DEMO OK");
process.exit(failed ? 1 : 0);
```
