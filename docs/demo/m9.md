## Wiederherstellungsprobe (Task 2)

`deploy/scripts/restore-rehearsal.sh` — ohne Docker, die App als Prozesse (Rolle `all`,
Worker eingeschlossen) aus `backend/`:

1. Datenbank A, App A, Demodaten (`scripts/demo_seed.py`) und ein Anhang (200 KB
   Zufallstext), eine Anmeldung des Demo-Admins;
2. `python -m app.ops backup create`, während A läuft, und `backup verify`;
3. A wird angehalten; leere Datenbank B und leere Ablage: `restore check` (kein Problem),
   `restore apply`;
4. `scripts/compare_databases.py A B`: je Tabelle Zeilenzahl und eine Prüfsumme des
   Inhalts, ohne Sitzungen, Anmeldeabläufe, Audit-Log und Sicherungsläufe (die der
   Restore verändert: Sitzungen gelöscht, `backup.restored`, `running` →
   `interrupted`);
5. App B: `/ready`, der Demo-Admin meldet sich an, das Sitzungs-Cookie von A gilt
   nicht (401), der Anhang lädt aus B mit demselben SHA-256 wie aus A;
6. eine manipulierte Kopie des Archivs (ein Byte im Anhang) scheitert an
   `restore check` mit `archive.member_checksum` (und `archive.checksum` über die
   Begleitdatei);
7. beide Apps angehalten, beide Datenbanken gelöscht, das Arbeitsverzeichnis entfernt.

### Anmeldung über OIDC mit Freigabe, Collab ohne Cookie

Gegen eine Test-Installation mit dem OIDC-Stub; braucht Node 22, `psql`, `curl`, `pgrep`,
das Backend (`uv`) und die `node_modules` des Collab-Pakets (für den Test-Client aus
`collab/test/helpers.mjs`). Die drei Dateien liegen nebeneinander in einem Verzeichnis
neben dem Arbeitsbaum (`../wt`):

1. `run-demo.sh` legt eine frische Datenbank an, macht ein Zertifikat für `localhost`
   (nur für diesen Lauf), startet den OIDC-Stub über https, den Mithörer `sniff.mjs`
   zwischen API und Collab-Prozess (er schreibt je WebSocket-Aufbau nur die Namen der
   Köpfe und den Anfang von `Authorization` auf, nie Werte) und die App in Rolle `all`
   (Migration, API, Worker, Collab-Prozess als Kind, `HERD_COLLAB_URL` zeigt auf den
   Mithörer). Die App bekommt `HERD_PUBLIC_URL`, `HERD_OIDC_ALLOWED_HOSTS=localhost`,
   das Secret des Stubs als `HERD_OIDC_STUB_SECRET` und das Zertifikat in
   `SSL_CERT_FILE`.
2. `demo_seed --oidc-stub https://localhost:19407` legt die Demodaten an und dazu den
   Anbieter „Demo-Anmeldung“ (allgemein, Secret als `env:HERD_OIDC_STUB_SECRET`,
   Selbstregistrierung für `demo.example`, eingeschaltet, „Prüfen“ grün).
3. `demo-m9.mjs` spielt zwei Browser: Dora (`dora.dorn@demo.example`) registriert sich
   über den Stub und landet auf „wartet auf Freigabe“, ohne Sitzung, auch beim zweiten
   Versuch; die Verwaltung sieht die Zahl, die Liste und die Benachrichtigung; eine
   fremde Domain wird abgelehnt; der Admin gibt Dora frei (ein zweites Freigeben mit
   derselben Version antwortet 409); Doras nächste Anmeldung öffnet eine Sitzung als
   `member` ohne `ai.use`; das Audit hat Registrierung und Freigabe. Dann bearbeitet
   Anna die Seite „Handbuch“ live über das Relay: Der Mithörer sieht keinen
   `Cookie`-Kopf, nur `Authorization: Bearer herd_cg_…`; `collab_grant` hat die
   Berechtigung nur als SHA-256; das Sitzungs-Cookie als Berechtigung an der internen
   API antwortet 401 `collab.grant_invalid`; der Collab-Prozess kennt nicht einmal den
   Namen des Cookies; die Änderung ist gespeichert.
4. Zum Schluss durchsucht das Skript das Protokoll der App nach Doras Adresse, Namen,

```js
#!/usr/bin/env node
// A TCP relay between the API and the collab process that records, for every WebSocket
// upgrade the API sends upstream, which headers it carries (names, and for
// Authorization only the token's prefix). Values are never written. LISTEN=…, TARGET=…, OUT=…
import { appendFileSync } from "node:fs";
import net from "node:net";

const [listen, target, out] = [Number(process.env.LISTEN), Number(process.env.TARGET), process.env.OUT];
net
  .createServer((inbound) => {
    const upstream = net.connect(target, "127.0.0.1");
    let head = Buffer.alloc(0);
    let seen = false;
    inbound.on("data", (chunk) => {
      if (!seen) {
        head = Buffer.concat([head, chunk]);
        const end = head.indexOf("\r\n\r\n");
        if (end >= 0) {
          seen = true;
          const lines = head.subarray(0, end).toString("latin1").split("\r\n");
          const names = lines.slice(1).map((l) => l.split(":")[0].toLowerCase());
          const auth = lines.find((l) => /^authorization:/i.test(l)) ?? "";
          const scheme = auth.replace(/^authorization:\s*/i, "").slice(0, 15);
          appendFileSync(out, JSON.stringify({ request: lines[0].split(" ")[0] + " " + lines[0].split(" ")[1].split("?")[0], headers: names, authorization: scheme }) + "\n");
        }
      }
      upstream.write(chunk);
    });
    upstream.on("data", (chunk) => inbound.write(chunk));
    const end = () => { inbound.destroy(); upstream.destroy(); };
    inbound.on("close", end); upstream.on("close", end);
    inbound.on("error", end); upstream.on("error", end);
  })
  .listen(listen, "127.0.0.1");
```
