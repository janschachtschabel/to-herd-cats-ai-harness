# Demo M8: Öffnung

Abnahme von Meilenstein 8 (Spezifikation 14): „Claude Code liest über `/mcp` nur Bereiche
seines Tokens; ein externer Agent schließt ein Ticket bis ‚Zur Prüfung‘ ab.“ Dazu, wie im
Plan M8 (Task 12) verlangt, ein interner Agent, der ein externes Werkzeug ruft, den
schreibenden Aufruf erst nach der Freigabe der fragenden Person. Ein echtes Claude Code
lief von hier aus nicht (kein Konto in der Sandbox); an seiner Stelle spricht der Client
des MCP-SDK (`mcp-client.py`, Streamable HTTP mit dem Handshake von 2025, das Token im
Kopf `Authorization`) genau das Protokoll, das Claude Code und Codex sprechen
([`MCP.md`](../MCP.md#einen-client-verbinden)).

## Was die Demodaten dazu anlegen

`backend/scripts/demo_seed.py` ruft nach den Daten von M1 bis M7 `backend/scripts/demo_mcp.py`
auf, alles über die öffentliche API:

- **MCP an:** der Schalter der Organisation (Clients zählen als Datenort `external`);
- **Annas Lesetoken** „Claude Code (Demo)“ nur für Team Nord;
- **mit Modell** (`HERD_DEMO_AI_*`; Agenten sieht und beauftragt nur, wer `ai.use` hat):
  der externe Agent **„Pipeline“** (Stufe 2, Anna verantwortlich, Bearbeiter in Team Nord)
  mit dem Schreibtoken **„CI-Pipeline“** und das Ticket **„Changelog für Release 1.4
  schreiben“**, das Anna ihm zuweist: Es wartet auf Abholung;
- **nur mit `--mcp-stub URL`** (ohne Argument nie ein Aufruf nach außen): der Server
  **„Tracker (Demo)“** auf diesem Stub mit dem geteilten Bearer-Konnektor
  „Tracker-Zugang“ (ein Zufallsschlüssel, verschlüsselt gespeichert), sein lesendes
  Werkzeug `search_issues` freigegeben, das schreibende `create_issue` offen für die
  Verwaltung.

Den Klartext eines Tokens gibt es nur in der Antwort, die ihn anlegt; das Skript verwirft
ihn sofort: nie ausgegeben, geloggt oder gespeichert. Wer ein Token nutzen will, legt sich
in der Oberfläche ein eigenes an. Die Nachrichten der Demodaten (M3) stehen seit diesem
Schritt in `backend/scripts/demo_messaging.py`, damit `demo_seed.py` kurz bleibt. Test:
`backend/tests/test_demo_mcp.py` (ohne Modell, mit Modell, mit Stub, das Argument).

## Ablauf

1. `run-demo.sh` legt eine frische Datenbank an, migriert, macht ein Zertifikat für
   `localhost` (nur für diesen Lauf) und startet den OpenAI-Stub, den MCP-Stub über https,
   die API und einen Worker als eigene Prozessgruppen. API und Worker bekommen
   `HERD_MCP_ALLOWED_HOSTS=localhost` (der Stub ist ein privater Host, den der Betrieb
   freigibt) und vertrauen dem Zertifikat über `SSL_CERT_FILE`.
2. `demo_seed` mit Modell (Stub) und `--mcp-stub https://localhost:19305/mcp`.
3. `demo-m8.mjs` prüft die Demodaten und dann:
   - **Abnahme 1, ein MCP-Client liest nur die Bereiche seines Tokens:** Die Verwaltung
     legt den Bereich „Vorstand“ mit der Seite „Budget 2027“ an, Anna darf ihn lesen (sie
     liest die Seite über REST); in Team Nord legt Anna einen Entwurf an. Anna legt ein
     Lesetoken nur für Team Nord an. `mcp-client.py` listet die Werkzeuge (nur die sechs
     lesenden), findet und liest „Urlaub“; „Budget 2027“ antwortet Wort für Wort wie eine
     unbekannte ID, die Suche findet es nicht, der Entwurf ist nicht lesbar, ein
     schreibendes Werkzeug gibt es für das Token nicht (JSON-RPC-Fehler -32602). Die
     Aufrufe stehen am Token (Werkzeug und Ergebnis, kein Inhalt). Widerrufen antwortet
     das Token 401 `token.invalid`.
   - **Abnahme 2, ein Skript als externer Agent:** Die Verwaltung stellt Pipeline ein
     Token für diesen Lauf aus. `pipeline-agent.py` ruft `list_my_tickets`, holt HC-13 mit
     `claim_ticket` ab („In Arbeit“), kommentiert und setzt „Zur Prüfung“; „Erledigt“ wird
     als Werkzeugfehler abgelehnt. Im Ticket: Status „Zur Prüfung“, weiter Pipeline
     zugewiesen, nicht mehr „Wartet auf Abholung“, Pipelines Kommentar und die
     Systemeinträge des Workers mit dem Namen des Tokens.
   - **Abnahme 3, ein interner Agent ruft ein externes Werkzeug mit Freigabe:** Die
     Verwaltung legt Theo (Stufe 4) an, gibt `create_issue` frei und teilt Theo
     `search_issues` (erlaubt) und `create_issue` (nach Freigabe) zu. Ben bittet Theo in
     der Direktnachricht um ein Issue. Theo sucht (sofort), dann wartet der schreibende
     Aufruf auf Ben: „Tracker (Demo) · create_issue“ mit genau den Argumenten; bis dahin
     ging nur die Suche an den Server. Nach der Freigabe bekommt der Server genau diese
     Argumente, beide Aufrufe mit dem Schlüssel des geteilten Konnektors (vom Server
     eingesetzt); das Journal hat je Aufruf zwei Einträge (wird gesendet, Antwort), die
     Freigabe sagt „ausgeführt“, Theo antwortet Ben.
   - **Logs:** In den Logs von API, Worker und Migration steht kein Token-Text (weder die
     dieses Laufs noch irgendein `herd_pat_…`/`herd_agt_…`) und kein Inhalt (Seitentext,
     Kommentar, Argumente, Ergebnis).

Die Oberfläche dazu prüfen die Browser-Tests `e2e/tests/mcp-tokens.spec.mjs`,
`mcp-external-agent.spec.mjs`, `mcp-servers.spec.mjs` und `mcp-agent-tools.spec.mjs` (mit
MCP- und OAuth-Stub über https, gestartet von `e2e/global-setup.mjs`): Token in der
Oberfläche anlegen und einmal sehen, Abholung live im Ticket, Katalog-Eintrag einrichten
und Werkzeuge (erneut) freigeben, persönliche OAuth-Verbindung bis zur Seite „Verbunden“,
Freigabekarte und Laufansicht, die persönliche Marke in einem Kanal und „Ausgang
unbekannt“ nach einem verlorenen Worker.

## Ausführen

Gegen eine Test-Installation mit Stubs; braucht Node 22, `psql`, `curl` und das Backend
(`uv`). Die vier Dateien liegen nebeneinander in einem Verzeichnis neben dem
Arbeitsbaum (`../wt`). Pfade und Ports sind die der Sandbox; `KEEP=1` lässt die Prozesse
laufen.

```bash
DEMO_ADMIN_PASSWORD=… DEMO_PASSWORD=… ./run-demo.sh
```

```js
#!/usr/bin/env node
// M8 demo against a running installation (an API and a worker of their own on one
// database) whose demo data came from `scripts.demo_seed` with the OpenAI stub as the
// model (HERD_DEMO_AI_*) and `--mcp-stub` pointing at the MCP stub (https, localhost).

// release. Token texts stay in this process: printed masked, never written anywhere;
// at the end the processes' logs are searched for them. Needs Node 22 and uv. Changes the

//   BASE=… STUB=… MCP_STUB=https://localhost:… ADMIN_EMAIL=… ADMIN_PASSWORD=… \
//     DEMO_PASSWORD=… NODE_EXTRA_CA_CERTS=… BACKEND=…/backend HERE=… LOGS=… node demo-m8.mjs

async function api(who, method, path, body) {
  const r = await fetch(BASE + path, {
    method,
    headers: {
      "Content-Type": "application/json",
      "X-Requested-With": "herd",
      ...(cookies[who] ? { Cookie: cookies[who] } : {}),
    },
    body: body === undefined ? undefined : JSON.stringify(body),
  });
  const set = r.headers.getSetCookie?.() ?? [];
  if (set.length) cookies[who] = set.map((c) => c.split(";")[0]).join("; ");
  const text = await r.text();
  return { status: r.status, body: text ? JSON.parse(text) : null };
}
async function get(who, path) {
  const r = await api(who, "GET", path);
  if (r.status !== 200) throw new Error(`GET ${path}: ${r.status} ${JSON.stringify(r.body)}`);
  return r.body;
}
async function send(who, method, path, body) {
  const r = await api(who, method, path, body);
  if (r.status >= 300) throw new Error(`${method} ${path}: ${r.status} ${JSON.stringify(r.body)}`);
  return r.body;
}
const login = (who, email, password) => send(who, "POST", "/api/auth/login", { email, password });
async function stub(base, path, body) {
  const r = await fetch(base + path, body === undefined ? {} : { method: "POST", body: JSON.stringify(body) });
  return r.json();
}
async function mcpRaw(secret, method) {
  const r = await fetch(`${BASE}/mcp`, {
    method: "POST",
    headers: {
      Authorization: `Bearer ${secret}`,
      "Content-Type": "application/json",
      Accept: "application/json, text/event-stream",
    },
    body: JSON.stringify({ jsonrpc: "2.0", id: 1, method }),
  });
  return { status: r.status, body: await r.json() };
}
function python(script, args, tokenEnv) {
  const run = spawnSync("uv", ["run", "--no-sync", "python", join(HERE, script), ...args], {
    cwd: BACKEND,
    env: { ...env, ...tokenEnv },
    encoding: "utf8",
  });
  return { code: run.status, out: run.stdout.trim(), err: run.stderr };
}

    const value = await probe();
    if (value) return value;
    if (Date.now() > deadline) throw new Error(`timed out: ${what}`);
    await sleep(250);
  }
}
```

```python
"""An MCP client for the M8 demo: the MCP SDK's own client (Streamable HTTP, the
handshake of 2025) against `<base>/mcp`, the access token from HERD_TOKEN in the
`Authorization` header, never in the URL. Lists the tools, then makes the calls given
as JSON (`[["tool", {arguments}], ...]`) and prints one JSON object: the tool names and
per call its error flag and text (or the protocol error's code). Never prints the token.

    HERD_TOKEN=… uv run --no-sync python mcp-client.py http://127.0.0.1:19300 '[["search", {"query": "Urlaub"}]]'
"""

import asyncio
import json
import os
import sys
from typing import Any

import httpx2
from mcp import Client
from mcp.client.streamable_http import streamable_http_client
from mcp.shared.exceptions import MCPError
from mcp.types import TextContent


async def main(base: str, calls: list[tuple[str, dict[str, Any]]]) -> dict[str, Any]:
    headers = {"Authorization": f"Bearer {os.environ['HERD_TOKEN']}"}
    async with httpx2.AsyncClient(headers=headers, timeout=30) as http:
        transport = streamable_http_client(f"{base}/mcp", http_client=http)
        async with Client(transport, mode="legacy", cache=None) as client:  # type: ignore[arg-type]
            listed = await client.list_tools()
            out: dict[str, Any] = {"tools": sorted(t.name for t in listed.tools), "calls": []}
            for name, arguments in calls:
                try:
                    result = await client.call_tool(name, arguments)
                except MCPError as error:
                    out["calls"].append({"tool": name, "protocol_error": error.code})
                    continue
                text = "\n".join(b.text for b in result.content if isinstance(b, TextContent))
                out["calls"].append({"tool": name, "is_error": result.is_error, "text": text})
    return out


if __name__ == "__main__":
    print(json.dumps(asyncio.run(main(sys.argv[1], json.loads(sys.argv[2]))), ensure_ascii=False))
```

```python
"""The external agent of the M8 demo: a script, as a CI pipeline would run Claude Code
or Codex, with the agent token from HERD_AGENT_TOKEN (never printed). Over `/mcp` with
the MCP SDK's client: `list_my_tickets`, then for the first ticket `claim_ticket`,
`comment_ticket` with the result of its work and `set_ticket_status` to the status
named in REVIEW (default „Zur Prüfung"); last it tries „Erledigt", which only a person
may set. Prints each step (tool, error flag, the server's text).

    HERD_AGENT_TOKEN=… uv run --no-sync python pipeline-agent.py http://127.0.0.1:19300
"""

import asyncio
import os
import re
import sys

import httpx2
from mcp import Client
from mcp.client.streamable_http import streamable_http_client
from mcp.types import CallToolResult, TextContent

COMMENT = "Changelog für 1.4 geschrieben: 3 neue Funktionen, 5 Korrekturen (siehe CHANGELOG.md)."


def text_of(result: CallToolResult) -> str:
    return "\n".join(b.text for b in result.content if isinstance(b, TextContent))


async def main(base: str) -> int:
    review = os.environ.get("REVIEW", "Zur Prüfung")
    headers = {"Authorization": f"Bearer {os.environ['HERD_AGENT_TOKEN']}"}
    async with httpx2.AsyncClient(headers=headers, timeout=30) as http:
        transport = streamable_http_client(f"{base}/mcp", http_client=http)
        async with Client(transport, mode="legacy", cache=None) as client:  # type: ignore[arg-type]

            async def step(tool: str, **arguments: object) -> CallToolResult:
                result = await client.call_tool(tool, arguments)
                print(f"{tool} error={result.is_error}: {text_of(result)}")
                return result

            mine = await step("list_my_tickets")
            found = re.search(r"key=(HC-\d+)", text_of(mine))
            if found is None:
                print("no ticket to pick up")
                return 1
            key = found.group(1)
            claimed = await step("claim_ticket", key=key)
            commented = await step("comment_ticket", key=key, text=COMMENT)
            moved = await step("set_ticket_status", key=key, status=review)
            done = await step("set_ticket_status", key=key, status="Erledigt")
    worked = not (claimed.is_error or commented.is_error or moved.is_error)
    return 0 if worked and done.is_error else 1


if __name__ == "__main__":
    sys.exit(asyncio.run(main(sys.argv[1])))
```
