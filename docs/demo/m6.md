# Demo M6: Agenten als Mitarbeiter

Abnahme von Meilenstein 6 (Spezifikation 14): „Ein Agent bearbeitet ein Ticket bis
‚Zur Prüfung‘; eine Freigabe für einen geänderten Inhalt wird abgelehnt; ein Lauf
übersteht den Neustart des Workers.“ Dazu die Demodaten mit Agenten bei der Arbeit
(Plan M6, Task 13) und eine Person ohne KI, die von alledem nichts sieht.

## Woher das Demo sein Modell bekommt

`backend/scripts/demo_seed.py` legt die Agenten nur an, wenn ein Modell eingestellt
ist (`backend/scripts/demo_ai.py`); ohne diese Variablen bleibt es bei den Demodaten von
M1 bis M4b:

| Variable | Bedeutung |
|---|---|
| `HERD_DEMO_AI_KIND` | schaltet die Agenten ein: `local` (ein OpenAI-kompatibler Endpunkt, den der Server über http erreicht, etwa der Stub der Tests oder ein lokaler Modellserver), `openai` oder `openai_compatible` |
| `HERD_DEMO_AI_URL` | Basis-URL des Endpunkts (nötig außer bei `openai`) |
| `HERD_DEMO_AI_MODEL` | Modell, Standard `gpt-6-luna` |
| `HERD_DEMO_AI_KEY_ENV` | Name einer Variable `HERD_AI_*` **des Servers**, die den Schlüssel hält; der Schlüssel selbst geht nie durch das Skript |
| `HERD_DEMO_AI_STUB` | Adresse des Stubs (`python -m tests.support.openai_stub`): Das Skript gibt ihm vor jedem Schritt die Antworten vor, jeder Lauf endet also wie beschrieben |

Mit einem echten Modell gehen dieselben Bitten hinaus, und das Skript wartet nur, bis
jeder Lauf endet (oder auf jemanden wartet), gleich was das Modell getan hat. Das
protokollierte Demo nutzt den Stub: kein Anbieter, kein Netz, jedes Ergebnis
wiederholbar.

## Ablauf

1. `demo_seed` legt wie bisher Anna (Moderatorin), Ben (Autor), Clara (Leserin), den
   Bereich „Team Nord“ mit den Seiten „Handbuch“ und „Urlaub“, Kanäle, Tickets und
   Sprints an. Mit Modell kommt dazu, alles über die öffentliche API:
   - die Verbindung „Demo-Modell“ als Standard-Zuweisung; Clara bekommt eine eigene
     Zuweisung „keine KI“;
   - Hilda (Stufe 1, Leserin in Team Nord) und Otto (Stufe 2, Autor, mit dem Skill
     „protokoll“ des Bereichs), verantwortlich ist Anna;
   - Ben fragt Hilda nach dem Urlaub; sie liest „Urlaub“ (`read_page`) und antwortet;
   - Anna legt das Ticket „Protokoll der Teamrunde schreiben“ an und weist es Otto zu;
     sein Lauf lädt den Skill, setzt „Zur Prüfung“ und kommentiert im Ticket;
   - Otto schlägt auf Annas Bitte eine Änderung am „Handbuch“ vor (offener Vorschlag)
     und merkt sich etwas (`update_memory`: die Seite `_agenten/otto/gedaechtnis`);
   - Otto darf Seitenänderungen danach nur noch mit Freigabe vorschlagen; Bens Bitte zu
     „Urlaub“ lässt seinen Lauf auf Bens Freigabe warten.
2. `demo-m6.mjs` prüft diesen Stand und dann die drei Abnahmepunkte:
   - **Ticket bis „Zur Prüfung“:** Ottos Ticket steht in einem Status der Kategorie
     `review`, sein Kommentar steht im Ticket mit seinem Lauf, das Journal zeigt
     `load_skill` und `set_ticket_status`, und in keinem Kanal von Team Nord steht etwas
     dazu.
   - **Freigabe für geänderten Inhalt:** Anna ändert „Urlaub“, danach gibt Ben die
     wartende Freigabe frei. Der Aufruf läuft nicht: Die API meldet die Freigabe als
     `outcome: stale`, es entsteht kein Vorschlag, das Modell bekommt `approval_stale`
     und antwortet.
   - **Neustart des Workers:** Anna bittet Otto um ein Ticket. Schritt 1 legt es an;
     während Schritt 2 auf den Anbieter wartet (der Stub antwortet erst nach 30 s), wird
     der Worker mit SIGKILL beendet und neu gestartet. Nach Ablauf der Lease (30 s)
     nimmt der neue Worker denselben Lauf wieder auf: ein Ticket, eine Antwort, im
     Journal jeder Modellschritt einmal, `recoveries` 1; der Anbieter sah Schritt 1
     einmal und Schritt 2 zweimal.
   - Clara (keine KI) bekommt den Lauf nicht (404), keine Freigaben und im Verzeichnis
     keinen Agenten.

Die Oberfläche dazu prüfen die Browser-Tests `e2e/tests/agents-work.spec.mjs` (Ticket
bis „Zur Prüfung“ in der Ticketansicht, Freigabe ausgeführt und „Veraltet“, Neustart
mitten im Lauf über die Steuerroute von `global-setup.mjs`, Erwähnung im Kanal mit
Antwort im Thread, Vorschlag aus einem Lauf angenommen, Gedächtnisseite unter
`_agenten`, eine Person ohne KI).

## Ausführen

Gegen eine Test-Installation mit API und eigenem Worker (etwa
`deploy/compose/compose.nodes.yml`) und dem Stub, den der Server erreicht. Braucht Node 22
und für `demo_seed` das Backend (`uv`). Beide Skripte ändern die Installation.

```js
#!/usr/bin/env node
// M6 demo against a running installation (API and a worker of its own) whose demo data
// came from `scripts.demo_seed` with the OpenAI stub as the model (HERD_DEMO_AI_*).
// Checks the agents at work that the demo left behind and the three acceptance points:
// a ticket worked up to „Zur Prüfung“; a release for content changed meanwhile is
// refused (stale, nothing runs); a run survives a worker killed in its middle.
// Needs Node 22. Changes the installation: test installations only.
//   BASE=http://127.0.0.1:8080 STUB=http://127.0.0.1:8099 ADMIN_EMAIL=admin@example.com \
//     ADMIN_PASSWORD=… DEMO_PASSWORD=… RESTART_WORKER='…' node demo-m6.mjs
// RESTART_WORKER: a shell command that kills the worker hard (SIGKILL) and starts it
// again, e.g. `docker compose kill -s SIGKILL worker && docker compose start worker`.
import { execSync } from "node:child_process";

const { BASE, STUB, ADMIN_EMAIL, ADMIN_PASSWORD, DEMO_PASSWORD, RESTART_WORKER } = process.env;
if (!BASE || !STUB || !ADMIN_EMAIL || !ADMIN_PASSWORD || !DEMO_PASSWORD || !RESTART_WORKER)
  throw new Error("BASE, STUB, ADMIN_EMAIL, ADMIN_PASSWORD, DEMO_PASSWORD, RESTART_WORKER");
const sleep = (ms) => new Promise((r) => setTimeout(r, ms));
let failed = false;
function check(what, ok, detail = "") {
  console.log(`${ok ? "OK  " : "FAIL"}  ${what}${detail ? ` (${detail})` : ""}`);
  if (!ok) failed = true;
}
const section = (title) => console.log(`== ${title}`);

// --- API helper: one cookie per person -----------------------------------------------
const cookies = {};
async function api(who, method, path, body) {
  const r = await fetch(BASE + path, {
    method,
    headers: { "Content-Type": "application/json", "X-Requested-With": "herd", Cookie: cookies[who] ?? "" },
    body: body === undefined ? undefined : JSON.stringify(body),
  });
  const text = await r.text();
  return { status: r.status, body: text ? JSON.parse(text) : null, headers: r.headers };
}
const ok = (r) => {
  if (r.status >= 300) throw new Error(`${r.status} ${JSON.stringify(r.body)}`);
  return r.body;
};
const get = async (who, path) => ok(await api(who, "GET", path));
async function login(who, email, password) {
  const r = await api(who, "POST", "/api/auth/login", { email, password });
  if (r.status !== 200) throw new Error(`login ${who}: ${r.status}`);
  cookies[who] = r.headers.get("set-cookie").split(";")[0];
}
async function stub(path, body) {
  const r = await fetch(STUB + path, {
    method: body === undefined ? "GET" : "POST",
    headers: { "Content-Type": "application/json" },
    body: body === undefined ? undefined : JSON.stringify(body),
  });
  if (!r.ok) throw new Error(`stub ${path}: ${r.status}`);
  return r.json();
}
const script = async (replies) => {
  await stub("/_stub/reset", {});
  await stub("/_stub/script", { replies });
};
const chats = async () => (await stub("/_stub/log")).filter((r) => r.path === "/v1/chat/completions");
const toolCall = (name, args) => ({ tool_calls: [{ name, arguments: args }] });
async function until(what, probe, seconds = 60) {
  const deadline = Date.now() + seconds * 1000;
  for (;;) {
    const value = await probe();
    if (value) return value;
    if (Date.now() > deadline) throw new Error(`timed out: ${what}`);
    await sleep(250);
  }
}
const newestRun = async (who, agentId) => (await get(who, `/api/runs?agent_id=${agentId}&limit=1`)).items[0];
const journal = async (who, runId) => (await get(who, `/api/runs/${runId}/events?limit=100`)).items;
const messages = async (who, id) => (await get(who, `/api/conversations/${id}/messages?limit=100`)).items;

await login("admin", ADMIN_EMAIL, ADMIN_PASSWORD);
for (const who of ["anna", "ben", "clara"]) {
  await login(who, `${who}.${{ anna: "nord", ben: "berg", clara: "klein" }[who]}@demo.example`, DEMO_PASSWORD);
}

section("1. The demo's agents: connection, assignments, two agents, a skill");
const space = (await get("anna", "/api/spaces?limit=100")).items.find((s) => s.name === "Team Nord");
const agents = (await get("admin", "/api/agents?limit=100")).items;
const hilda = agents.find((a) => a.name === "Hilda");
const otto = agents.find((a) => a.name === "Otto");
const connections = (await get("admin", "/api/ai/connections?limit=100")).items;
const model = connections.find((c) => c.name === "Demo-Modell");
check("Connection „Demo-Modell“ (local, to the stub) is the standard assignment",
  model?.kind === "local" && (await get("admin", "/api/ai/assignments")).default?.connection_id === model.id,
  model?.base_url);
const perms = async (who) => (await get(who, "/api/auth/me")).permissions;
check("Anna and Ben have AI, Clara not (her own assignment: no AI)",
  (await perms("anna")).includes("ai.use") && (await perms("ben")).includes("ai.use") && !(await perms("clara")).includes("ai.use"));
check("Hilda level 1, Otto level 2, both active, Anna responsible",
  hilda?.level === 1 && otto?.level === 2 && hilda.status === "active" && otto.status === "active");
const skills = (await get("admin", `/api/agents/${otto.id}/skills`)).skills;
check("Otto has the space's skill „protokoll“", skills.length === 1 && skills[0].name === "protokoll" && skills[0].available);

section("2. Acceptance 1: Otto works a ticket up to „Zur Prüfung“");
const tickets = (await get("anna", `/api/tickets?space_id=${space.id}&q=Teamrunde&limit=100`)).items;
const ticket = await get("anna", `/api/tickets/${tickets[0].number}`);
check("The ticket is Otto's and its status of category review", ticket.assignee?.id === otto.id && ticket.status.category === "review",
  `${ticket.key} „${ticket.title}“: ${ticket.status.name}`);
const ticketThread = await get("anna", `/api/tickets/${ticket.number}/thread`);
const comments = (await messages("anna", ticketThread.id)).filter((m) => m.kind === "agent");
check("Otto's answer is a comment in the ticket's thread, with its run", comments.length === 1 && comments[0].run_id,
  comments[0]?.body_md);
const ticketRun = await get("anna", `/api/runs/${comments[0].run_id}`);
const ticketCalls = (await journal("anna", ticketRun.id)).filter((e) => e.kind === "tool_call").map((e) => e.content.name);
check("The run's journal: load_skill, then set_ticket_status; asked by Anna; completed",
  JSON.stringify(ticketCalls) === '["load_skill","set_ticket_status"]' && ticketRun.stop_reason === "completed",
  `${ticketRun.steps} steps, place ${ticketRun.place.kind}`);
const channels = (await get("anna", `/api/spaces/${space.id}/channels?limit=100`)).items;
let quiet = true;
for (const channel of channels) {
  for (const m of await messages("anna", channel.id)) if (m.author?.type === "agent" || m.body_md?.includes(ticket.key)) quiet = false;
}
check("Nothing about it in Team Nord's channels", quiet, channels.map((c) => `#${c.name}`).join(", "));

section("3. The rest of the demo: an answer, a proposal, memory, a pending release");
const withHilda = ok(await api("ben", "POST", "/api/dms", { agent_id: hilda.id })); // the existing one
const answer = (await messages("ben", withHilda.id)).filter((m) => m.kind === "agent");
check("Ben asked Hilda about leave; she read „Urlaub“ and answered", answer.length === 1, answer[0]?.body_md);
const proposals = (await get("anna", `/api/spaces/${space.id}/proposals?state=open&limit=100`)).items;
check("Otto's open proposal for „Handbuch“, marked as AI, with its run",
  proposals.length === 1 && proposals[0].ai && proposals[0].author.type === "agent" && proposals[0].run_id);
const tree = (await get("anna", `/api/spaces/${space.id}/pages/tree?limit=100`)).items;
const memory = tree.find((p) => p.path === "_agenten/otto/gedaechtnis");
const memoryPage = memory && (await get("anna", `/api/pages/${memory.id}`));
check("Otto's memory page under _agenten, written by Otto", memoryPage?.updated_by.type === "agent", memoryPage?.content_md.trim());
const pending = (await get("ben", "/api/approvals?state=pending&limit=100")).items;
check("A release waits for Ben: Otto's page proposal for „Urlaub“", pending.length === 1 && pending[0].tool === "propose_page_change",
  pending[0]?.summary);
const waitingRun = await get("ben", `/api/runs/${pending[0].run_id}`);
check("Its run waits", waitingRun.state === "waiting");

section("4. Acceptance 2: a release for content changed meanwhile is refused");
const leave = tree.find((p) => p.title === "Urlaub");
const before = await get("anna", `/api/pages/${leave.id}`);
ok(await api("anna", "PATCH", `/api/pages/${leave.id}`, {
  content_md: before.content_md + "- Brückentage sind frei.\n",
  version: before.version,
}));
await script([{ content: "Die Seite hatte sich geändert; ich frage neu, wenn nötig." }]);
const decided = ok(await api("ben", "POST", `/api/approvals/${pending[0].id}/decide`, { decision: "approve", version: pending[0].version }));
check("Ben releases it after Anna changed the page", decided.state === "approved");
const settled = await until("the run ends", async () => {
  const run = await get("ben", `/api/runs/${waitingRun.id}`);
  return run.state === "done" ? run : null;
});
const outcome = (await get("ben", `/api/approvals/${pending[0].id}`)).outcome;
check("The API reports the release as stale: nothing ran", outcome === "stale", `outcome ${outcome}`);
const leaveProposals = (await get("anna", `/api/spaces/${space.id}/proposals?limit=100`)).items.filter((p) => p.page_id === leave.id);
check("No proposal for „Urlaub“ was made", leaveProposals.length === 0);
const staleCall = (await journal("ben", settled.id)).find((e) => e.kind === "tool_call");
check("The journal's tool call says approval_stale; the model answered", staleCall?.content.text.startsWith("approval_stale") && settled.stop_reason === "completed",
  (await messages("ben", pending[0].conversation_id)).filter((m) => m.run_id === settled.id && !m.card).map((m) => m.body_md).join(" "));

section("5. Acceptance 3: a run survives a worker killed in its middle");
const anna2otto = ok(await api("anna", "POST", "/api/dms", { agent_id: otto.id })); // the existing one
const title = "Neustart-Probe";
await script([
  toolCall("create_ticket", { space_id: space.id, title }),
  { content: "Diese Antwort geht mit dem Worker verloren.", delay: 30 },
  { content: "Das Ticket ist angelegt." },
]);
const previous = await newestRun("anna", otto.id);
ok(await api("anna", "POST", `/api/conversations/${anna2otto.id}/messages`, { body_md: "Lege bitte ein Ticket Neustart-Probe an." }));
const probe = async () => (await get("anna", `/api/tickets?space_id=${space.id}&q=${title}&limit=100`)).items.filter((t) => t.title === title);
await until("step 1 made the ticket", async () => (await probe()).length === 1);
await until("step 2 waits on the provider", async () => (await chats()).length === 2);
const running = await newestRun("anna", otto.id);
check("Step 1 is done (ticket made), step 2 waits on the provider", running.id !== previous?.id && running.state === "running");
const t0 = Date.now();
execSync(RESTART_WORKER, { stdio: "inherit", shell: "/bin/bash" });
console.log(`      worker killed (SIGKILL) and started again`);
const recovered = await until("the run ends", async () => {
  const run = await get("anna", `/api/runs/${running.id}`);
  return run.state === "done" ? run : null;
}, 90);
check("The same run ends completed, taken up after the lost worker", recovered.stop_reason === "completed" && recovered.recoveries >= 1,
  `recoveries ${recovered.recoveries}, ${((Date.now() - t0) / 1000).toFixed(1)} s after the kill`);
check("Exactly one ticket", (await probe()).length === 1);
const answers = (await messages("anna", anna2otto.id)).filter((m) => m.run_id === running.id).map((m) => m.body_md);
check("Exactly one answer, not the lost one", JSON.stringify(answers) === '["Das Ticket ist angelegt."]', answers.join(" | "));
const events = await journal("anna", running.id);
const steps = events.filter((e) => e.kind === "model_call").map((e) => e.content.step);
const calls = events.filter((e) => e.kind === "tool_call").map((e) => e.content.name);
check("Journal: one tool call, each model step once", JSON.stringify(calls) === '["create_ticket"]' && JSON.stringify(steps) === "[1,2]",
  `steps ${steps.join(",")}`);
check("Provider: step 1 once, step 2 twice (lost, then again)", (await chats()).length === 3);

section("6. Clara (no AI) sees none of the agents' machinery");
check("Clara: the run 404", (await api("clara", "GET", `/api/runs/${ticketRun.id}`)).status === 404);
const herApprovals = await api("clara", "GET", "/api/approvals");
check("Clara: no releases", herApprovals.status === 404 || herApprovals.body.items.length === 0, `status ${herApprovals.status}`);
const directory = await get("clara", `/api/directory?q=Ot&space_id=${space.id}`);
check("Clara: no agent offered in the directory", !directory.items.some((e) => e.type === "agent"));

console.log(failed ? "DEMO FAILED" : "DEMO OK");
process.exit(failed ? 1 : 0);
```
