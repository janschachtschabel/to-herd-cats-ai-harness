# M2 Wiki Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ein vollwertiges Team-Wiki je Bereich: Seitenbaum, Markdown-Editor, Live-Bearbeitung mit Generationen, Versionen mit Diff und Wiederherstellung, Papierkorb, Tags, Anhänge, Volltextsuche, Import und Export.

**Architecture:** Neues Modul `app/modules/wiki` nach dem Muster aus M1 (`router → service → repository`, Rechte nur über `core/access.py`, Audit über `audit.record`). Markdown in `page.content_md` ist kanonisch. Ein Node-Prozess `collab/` (Hocuspocus) hält Live-Sitzungen und spricht ausschließlich über `/internal/collab/*` (Port 9090, Token) mit der API. Die API leitet `/collab` per WebSocket an ihn weiter.

**Tech Stack:** wie M1; dazu Tiptap 3 (`@tiptap/react`, `@tiptap/starter-kit`, `@tiptap/markdown`, Collaboration, CollaborationCaret, Table, TaskList, Image), Yjs, `@hocuspocus/server` + `@hocuspocus/provider` + `@hocuspocus/transformer` (alle MIT), `react-markdown` + `remark-gfm`, `websockets` (Python, BSD) für die Weiterleitung.

**Spec:** `docs/superpowers/specs/2026-11-12-to-herd-cats-ai-design.md` (Abschnitte 9, 10 „Tags“, 11 „Suche“ nur Volltext, 4.1, 12, 13, 14/M2)

## Global Constraints

- Alle Global Constraints aus `docs/superpowers/plans/2026-11-12-m1-fundament.md` gelten unverändert.
- Jede Wiki-Aktion prüft über `require(session, actor, Action.<...>, space_id)`. Unsichtbare Bereiche und Seiten darin antworten mit 404 (`space.not_found` bzw. `page.not_found`), nie mit 403.
- Listen, Baum und Suche filtern in SQL über `visible_space_ids(actor)`.
- Markdown ist die einzige gespeicherte Inhaltsform einer Seite. Yjs-Zustand ist nur Sitzungszustand in `page_collab_state`.
- Gespeichert wird eine Seite ausschließlich über `PageService`. Auch der Collab-Prozess speichert über die interne API und nie direkt in die Datenbank.
- Rohes HTML in Markdown wird nie ausgeführt: Die Anzeige rendert ohne `rehype-raw`; Links nur mit `http`, `https`, `mailto` und relativen Zielen.
- Neue Rechte in `core/permissions.py`: `page.create`, `page.edit` (ab `editor`), `page.publish`, `page.trash`, `page.moderate` (ab `moderator`). Eigene Entwürfe darf ein `editor` selbst veröffentlichen.
- `/internal/*` verlangt den Header `X-Herd-Internal-Token` gleich `HERD_INTERNAL_TOKEN` (Vergleich in konstanter Zeit). Ohne gesetztes Token antwortet `/internal/*` immer mit 503 `internal.disabled`.
- Grenzen: Markdown je Seite höchstens 200.000 Zeichen, Yjs-Zustand höchstens 5 MB, Anhang höchstens 25 MB (`HERD_ATTACHMENT_MAX_BYTES`), höchstens 16 Pfadsegmente.
- Felder für spätere Meilensteine entstehen nicht in M2: `no_ai` (M5), `review_due_at` (M7), `page_proposal` (M6), Embeddings (M5).

## Review Focus

1. **Alte Live-Sitzung überschreibt neuen Stand:** Nach Speichern im Markdown-Modus, Wiederherstellen oder Verschieben sendet ein noch offener Editor seinen alten Yjs-Stand. Erwartet wird die Ablehnung mit `collab.generation_ended`, und der gespeicherte Stand bleibt unverändert. Task 8.
2. **Rechteentzug während der Live-Sitzung:** Einer Person wird die Autorenrolle entzogen, während sie tippt. Erwartet wird, dass ihre nächste Änderung abgewiesen und die Verbindung geschlossen wird. Task 8.
3. **Verschieben in den eigenen Unterbaum:** Eine Seite wird unter eine ihrer Unterseiten verschoben. Erwartet wird 409 `page.move_cycle`. Task 2.
4. **Suche verrät Verborgenes:** Ein Suchbegriff, der nur in einem fremden Team-Bereich vorkommt, liefert für Nichtmitglieder keine Treffer und keine Zählung. Task 5.
5. **Gefährliche Uploads:** Eine als `bild.png` benannte HTML- oder SVG-Datei wird abgelehnt (Prüfung des Inhalts, nicht nur der Endung). Task 6.

- Create: `collab/{package.json,package-lock.json,server.mjs,api.mjs,markdown.mjs,schema.mjs}`, `collab/test/{markdown,server}.test.mjs`, `backend/app/web/collab_proxy.py`, `backend/tests/test_collab_proxy.py`
- Modify: `backend/app/launch.py` (Rolle `collab`; `all` startet den Node-Prozess als Kind), `Dockerfile` (Node-Laufzeit und `collab/` ins Image), `backend/app/core/config.py` (`collab_url = "ws://127.0.0.1:1234"`, `collab_port = 1234`)
- Port: ai-2 `runtime/collaboration.mjs`, `editor/{markdown,schema}.mjs`, `tests/wiki-runtime.test.mjs`

**Interfaces:**
- Consumes: Schnittstelle aus Task 8
- Produces:
  - `collab/server.mjs`: Hocuspocus auf `HERD_COLLAB_PORT` (Standard 1234, bindet `127.0.0.1` bei `HERD_ROLE=all`, sonst `0.0.0.0`), Dokumentname `page:<uuid>`.
    - `onAuthenticate`: liest das Sitzungs-Cookie aus den Request-Headern (nie aus einem vom Client gesendeten Token-Feld) und ruft `/internal/collab/auth`.
    - `onLoadDocument`: lädt Zustand; ohne `ydoc_b64` wird das Dokument aus Markdown aufgebaut (`markdown.mjs`).
    - `onStoreDocument` (entprellt 2 s, spätestens nach 10 s): wandelt in Markdown um und ruft `PUT`. Bei 409 schließt es alle Verbindungen des Dokuments mit Code 4409 und Grund `generation_ended`; bei 403 schließt es die Verbindungen der betroffenen Personen mit 4403.
    - Alle 5 s `check` je offenem Dokument.
    - Grenzen: 200 Verbindungen, 1 MB je Nachricht.
    - Eigener HTTP-Port ist nicht nötig; `/health` beantwortet der Prozess auf demselben Port per HTTP 200 für die Probe.
  - `collab/markdown.mjs`: `markdownToYDoc(md) -> Y.Doc`, `yDocToMarkdown(ydoc) -> string`. Unterstützt: Überschriften, Absätze, fett, kursiv, durchgestrichen, Inline-Code, Links, Bilder, Listen, Aufgabenlisten, Zitate, Codeblöcke, Tabellen, Trennlinien. Nicht unterstützte Konstrukte bleiben als Codeblock mit Sprache `raw-markdown` erhalten und gehen nie verloren.
  - `backend/app/web/collab_proxy.py`: WebSocket-Route `/collab` in der öffentlichen App, die beide Richtungen an `Settings.collab_url` durchreicht und dabei `Cookie` und `Origin` weitergibt. Sie lehnt Verbindungen ab, deren `Origin` nicht zu `HERD_PUBLIC_URL` passt (403).
  - `launch.py`: Bei `all` wird `node collab/server.mjs` als Kindprozess gestartet, bei dessen Ende beendet sich der Launcher mit Code 3; SIGTERM wird weitergereicht.
  - Metrik `herd_collab_connections` (Gauge, von der Weiterleitung gezählt).

`collab/test/markdown.test.mjs` (node:test): Round-Trip-Fixtures je unterstütztem Konstrukt (`md → ydoc → md` ist stabil nach einem Durchlauf), `unsupported syntax survives as raw block`. `collab/test/server.test.mjs`: gegen eine nachgebildete interne API: `rejects connection without cookie`, `closes with 4409 when api answers generation_ended`, `closes revoked user with 4403`, `stores markdown after edit`. `backend/tests/test_collab_proxy.py`: `rejects foreign origin`, `relays frames both ways` (gegen einen lokalen Echo-WebSocket), `forwards cookie header`.
